# 白龙娘会怎样邀你玩，又怎样陪你工作？

2026-11-21 · 电子宠物互动设计调研 · 网页像素版

**建议先试一个小场景：你把手指停下来，她自己蹭完最后一下。** 白龙娘已经会跟手顺毛、接星和回礼。接下来最值得观察的是，第一次见她的人能否看出她也有想做的事，自己的停顿、松手或改摸别处会怎样影响她。这一轮的产出是调研与候选分镜。

## 三个候选场景，按试做顺序排列

### 1. 她把额头送过来

第一次打开，在空闲、手指已离屏时也有机会遇到。她自己理一下刘海，把一侧额头送出来，再看向正前方停住。这个停顿就是玩家的回合。想表达的性格是“明明想被摸，还要先装成在理头发”。

| 玩家接下来做什么 | 她怎么接 |
| --- | --- |
| 手指停在她送出的那侧 | 她主动往指边蹭一小下，闭眼靠住。让露在手指外的另一只眼或尾尖慢半拍放松，接触反馈仍然看得见。 |
| 顺着刘海移动，再停住 | 移动时接现有顺毛。停住后，她自己补完半下，靠稳就停。用户能故意做一次“动、停、再动”，看出谁带动了哪一拍。 |
| 只点一下就松开，或落在另一侧 | 轻点就眨眼回礼；点在另一侧就先转眼找那只手。提前松手时在原位抬头，避免往已经离开的指尖追蹭。 |
| 一直没碰，或她已经蹭够了 | 没人接，她就把刚才翘起的刘海压平，自己坐好。同一轮已蹭够时，她轻轻偏开，尾尖放松，留一拍再回到待机。 |

逐帧先看偏头时龙角与额头的相对位置、接触时发梢止在哪里、松手时身体重心怎样回正。动作幅度用原生像素帧分别画出，避免整张脸缩放。全身与近景都要能在指腹遮住半张脸时读懂结尾。在同一次安静等待里，只邀一次，之后照原节奏休息。沿用现有减少动态效果设置时，可由玩家先轻点额头，再用静止的侧头姿势承接。

### 2. 她用尾尖学你敲拍子

她用尾尖轻轻敲自己摊开的爪垫两下，再把尾尖收开，将爪垫留给你。你可以轻点两三下，也可以在中间故意停很久。她先看着每次落点，等你停下，再用尾尖敲回刚才的节奏。如果你只点一下，她就认真回一下。如果你没接，她把爪子收回来，自己敲完。尾尖与爪垫的轮廓在两种取景中都要读得清，触摸范围可以覆盖掌边。

这一幕给了用户一个能主动试验的变化。下一轮故意把两次敲击之间的空隙拉长，听不到声音也能靠尾尖的接触和停顿辨认。建议只在她明确伸出爪垫时接收节拍，平时连点鼻尖、揉脸仍各有自己的含义。原画先查尾尖能否自然碰到同侧爪垫；若近景里必须拉长尾巴才能够到，就改让一只爪子轻拍另一只。模仿的依据来自宝可梦原作。AR 运动实验则比较过虚拟狗模仿用户、随机行动和无狗三种条件，可借用它的对照思路来测圆屏效果。[宝可梦模仿玩法](https://www.pokemon.co.jp/ex/xy/system/09.html) · [Nam 等，AR Fitness Dog](https://pubmed.ncbi.nlm.nih.gov/40063470/)

### 3. 下一次打开，她留着你翻过的那一页

借用现有的月牙页与星图页。用户亲手翻到月牙并松手落页之后，再一次进入阅读，她从月牙页开始，看到卷起的书角，伸爪把它抚平。用户可以翻回星图，下一次就以新选择为准。拖到一半又松手、自动演示、回放事件都不写入这段共同经历。它只需记住本机最近一次真正翻到哪页。

这也是最适合 Codex 工作场景的一项。阅读时碰她，留一爪压在书上回应；新状态到来，就收好道具转入相应工作。等待确认仍让圆屏读得出等待，击掌只算招呼。额度与上下文各自显示已有读数。这样低额度也能遇见心情很好的她，用户可以分辨工作状态和角色心情。[当前工作场景与读数约定](../design/pixel-badge/README.md)

## 用什么判断值得继续做

首轮可邀请 6 位没玩过的人，让一半先看当前版，一半先看候选分镜或可交互样机。保持角色、镜头、暮紫背景和画面尺寸一致，收起圆屏外的玩法说明。先观察，再问一句“刚才发生了什么”。以下是下一轮的试验设计，本轮尚无用户数据。

| 要验证的问题 | 怎么观察 | 怎样决定下一步 |
| --- | --- | --- |
| 她的邀请能被发现吗？ | 首次给自由观察时间，记录是否主动碰她、第一下落在哪里。事后把主动选择旁观与完全没看懂分开记。 | 若多人把邀请理解成普通理发，先改回望方向和停姿。通过外部提示才完成的，单独计数。 |
| 用户能感到她在跟自己玩吗？ | 在节奏试验中，用相同尾尖动作分别复现本人节拍和回放别人的节拍，交换顺序。记录参与者是否会主动换个节奏验证，能否说出两次的差异。 | 如果两版都像固定循环，优先检查敲击开始、停顿和交回回合的时机。 |
| 安静陪伴会不会打断工作？ | 请参与者读一小段文字。期间故意略过一次邀请，再触发一次真正的 Agent 等待。记录重复邀玩、回头查看及把两者混淆的次数。 | 调整宠物邀玩的频率与姿势，让需要电脑端处理的等待信号继续容易辨认。 |
| 再次见面时能感到连续吗？ | 第二次打开前先请参与者说出上次留下哪页；再次进入阅读后，记录是否自发认出、翻动或提及它。 | 区分“程序记对了”和“人认出来了”。若只做到前者，优先提高页角图案在原尺寸下的辨识度。 |

网页先验证邀请与轮流互动，再将通过的分镜放到 **1.75 英寸、466 × 466 的电容圆屏**，分别手持、佩戴重试。左右手都试一次，观察指腹遮挡、圆边裁切和轻点误判。可触区域优先覆盖整侧额头或整只爪垫，关键回应落在手指以外。具体停顿、触摸容差和邀玩间隔由这两轮结果确定。[微雪设备规格](https://docs.waveshare.net/ESP32-S3-Touch-AMOLED-1.75C/)
