# 开发顺序、验收与风险关闭

下表保留最初的分阶段验收目标。当前代码进展见本页的需求追踪，设备操作见[圆屏互动触发手册](18-device-interactions.md)。

## 分阶段交付

| 阶段 | 交付与依赖 | 通过标准 | 估计专注工作量 |
| --- | --- | --- | --- |
| G0 准备 | 需求、目录、协议、状态核心、原型、素材索引、环境核查 | 文件可读，离线检查通过，构建结论有证据 | 本轮 |
| G1 板卡基线 | 1.75C 诊断固件，屏幕、触摸和 PMIC 独立检查 | 色条正确、触摸准确、PSRAM识别、30 min不重启；记录板号和端口 | 1–3 日 |
| G2 角色与 UI | 资源转换、主屏/详情/设置、姿态和轻动效 | 四角色可切、未知/过期正确、缺资源回退、30–60 cm可读 | 3–5 日 |
| G3 USB 联通 | C协议解析、握手、快照、重连、会话意图 | 连续100次断连可恢复、噪声/坏帧不崩溃，端到端目标可测 | 2–3 日 |
| G4 真 Agent | Codex先、Claude其次；会话选择与真实额度 | 每种实际操作与设备匹配；账号/会话不串；无Hook阻塞 | 3–6 日 |
| G5 稳定与佩戴 | 电源、配置、资源恢复、桥接程序打包 | 8 h桌面稳定、实测耗电、完整升级/回退步骤 | 2–4 日 |

工作量约 11–21 个专注工作日，不含购买等待、重新绘制角色或外部 API 变化。阶段顺序可交叉做电脑端离线工作，但不跳过硬件 Gate。先完成 Codex + GPT 单角色完整链路，再扩角色和 Claude，能更快发现真正风险。

| R07 通信 | USB 配对与配网。USB、Wi-Fi 和 BLE 共用签名快照、租约与应用入口，支持过期、重复、竞争和重连。 | 客户端自动择路、不同路由器兼容性、断连恢复和长时间共存表现。 |
| R08 素材与渲染 | 角色使用本地素材、局部 RGB565 绘制和 DMA。鲸鱼娘缺少高清呼吸分区时使用内置高清姿态。GPT 独立脸部动作包损坏时仍能待机、跟眼和摸头。 | 核心像素包或基础姿态包损坏后的可视恢复页面及现场恢复流程。 |
| R09 电源 | 两个角色的主画面显示 PMIC 实测供电状态与可用电量，支持 USB 供电、无电池、电量未知和充电提示。 | 面向用户的亮度调节、闲置降亮与唤醒、不同供电条件的实测功耗与续航。 |
| R10 验证与交付 | ESP-IDF 5.5.4 构建、主机与像素回归、COM21 实际 USB／BLE／Wi-Fi 收发，产品探针统计角色 RGB565 变化、传输错误和 DMA 内存。 | 无线版持续 8 小时、事件到屏幕出光的延时分布、不同供电条件与面向用户的更新回退。 |

触摸采样目前保留最新一次按压的起点、终点、时间和最大偏移。如果同一显示间隔内发生多次完整的独立点击，应用只能还原最后一次。事件桥同样会合并突发的中间状态；设备呈现最近状态，需要逐条观看演示可使用带时间间隔的回放。[输入结构](../components/baji_runtime/include/baji_input.h) · [无线回放](17-wireless-agent.md)

另有一个低频恢复边界：若 NimBLE 底层在拆除协议栈中途返回硬错误，驱动保留首次错误，后续启动需要复位以重建设备状态。这是从错误路径审查得出的限制，发生频率待实机长测。[BLE 启停逻辑](../components/baji_ble/baji_ble.c)

## 实机性能验收

所有数字是目标，实测结果写入 `08-validation-log.md`：
- 状态事件到可见变化 P95 <500 ms；触摸反馈 P95 <100 ms。
- 姿态/轻动效目标 10 fps，连续 30 min 无明显卡死；最终以可见质量和帧耗时分布评判。
- USB 8 s 无合法快照进入离线；重连收到新快照后 1 s 内恢复主屏。
- 角色包缺失、CRC 错误或缺图时，显示内置保底图形并继续运行。
- 8 h 连续工作无异常重启、无持续内存下降；同时记录最大连续内存块，不能只看总量。
- 指标过期后主屏不显示旧数字；0%已用与未知有可见差别。
- 相同 request_id 重发只执行一次会话切换或固定操作。
- 低亮模式和减少动效模式都能辨认等待/错误；不依赖快速闪烁。

## 尚待关闭的事实项

- 实物的供电方式、是否安装电池、设备端口及运行时内存容量。
- 当前 5.5.4 固件的显示方向、触点误差、亮度和连续运行表现。
- 当前桌面客户端可暴露哪些 Hook/usage 字段，是否有唯一会话关联。
- 本机账号可返回哪些额度桶，如何确认与选中会话同账号。
- 源姿态归一化后的脸部大小、透明混合性能和实屏颜色。

这些不阻止当前规格和离线准备完成，也不能被演示数据“补齐”。G1/G4 用实测关闭后再更新状态。
