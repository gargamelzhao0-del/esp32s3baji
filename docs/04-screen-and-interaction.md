# 466 × 466 圆屏与互动设计

可运行原型：`../design/badge-prototype.html`。原型用于讨论布局、状态和触摸反馈，全部指标为演示数据；浏览器帧率不能作为 ESP32 的性能证明。

## 画面层级

一眼先看角色和是否需要我，再看客户端、模型，最后看额度。主屏固定四层：黑底主题氛围 → 角色 → 状态提示 → 简短信息。装饰不承载真假不明的数值，颜色也不是唯一状态信号。

| 区域 | 设计坐标 / 用途 |
| --- | --- |
| 外围状态环 | 圆心 (233,233)，半径 221，线宽 3；表达连接/工作状态，不同时表达额度 |
| 客户端标题 | 中心 x=233，y≈48–62；20–22 px |
| 具体模型 | 中心 x=233，y≈77–94；18–20 px，长型号省略，详情展示完整值 |
| 角色容器 | x≈88，y≈99，w≈290，h≈253；完整保留头饰和脸，脚底固定 |
| 状态胶囊 | x≈113，y≈354，w≈240，h≈32；21–22 px，独立文字 |
| 数值带 | y≈391–438；“额度剩余”与“上下文”分别标注，标签18 px，数值21 px |
| 底部连接点 | y≈442；只放 USB / 固定等短标志，详细信息移到详情页 |

坐标不是简单方形安全框：所有文字和按钮要按圆边界检查。触摸目标至少 44 × 44 px；边缘 12 px 以内不放必要按钮。关键文案不小于 18 px；状态文字 22 px。图形可放宽到圆边缘，脸和数字不能被裁切。

主屏不展示提示词、文件路径、长错误、完整日志、密集 Token 明细。型号变化后显示 1 次轻提示，但不反复弹窗。

## 四个页面

| 页面 | 内容 |
| --- | --- |
| 角色主页 | 主题 / 型号 / 角色 / 当前阶段 / 主额度剩余 / 上下文 |
| 使用详情 | 各额度桶已用和重置、来源或估算、更新时间、Token 范围；过期显示 — 与“数据过期” |
| 会话页 | 最多四个摘要、选择依据、固定状态；不显示私有项目路径 |
| 设置页 | 亮度、减少动效、闲置休眠、连接、角色包信息；电池/USB 信息 |

Codex：近黑背景、偏冷的浅青状态色、清晰排版和少量终端元素。Claude Code：黑底搭配暖橙、柔和光晕和书页意象。角色仍由模型决定。默认主题为灰蓝，未知模型不冒充 GPT。没有真实额度时，用 — / 暂不可用，不保留演示百分比。

## 状态与动效

| 条件 | 姿态 / 视觉 | 主文案 |
| --- | --- | --- |
| idle | idle，2 px 慢呼吸 | 待命 |
| working | thinking，轻点状循环 | 工作中 |
| tool + reading / writing / searching / running | 对应静态姿态，图标小幅活动 | 阅读中 / 写入中 / 搜索中 / 执行工具 |
| waiting | asking，低频琥珀呼吸环 | 等待你确认 |
| ended + unknown | idle，短暂结束标记 | 本轮已结束 |
| ended + succeeded | happy，最多 1.6 s 单次反馈 | 已确认完成 |
| error | oops，固定错误标志 | 发生异常 |
| limited | tired，额度标志 | 已达限制 |
| offline | 冻结当前姿态，降低饱和度，停止工作循环 | 连接已断开 |

额外状态：未绑定显示“等待电脑连接”；无会话显示“等待会话”；资源缺失显示保底角色和小图标，详情可查资源错误。低电不把角色表情强制切换为额度不足，避免混淆。

## 手势与冲突规则

GPT 主页在角色两侧留了各 65 × 65 设计像素。左侧按钮显示当前可参与的工作，右侧口袋包含工作、陪玩、穿戴和互动音效。弹层避开底部的 Agent 状态和额度。书角、键盘、纸鹤的命中区域随实际画面移动。工作互动期间，换会话、切模型、离开角色页或切换工作阶段都会收起对应的道具。等待确认时碰手只产生角色回应，确认仍在电脑进行。[工作互动表](../design/gpt-pet/README.md#白龙的口袋)

GPT 网页原型中，揉额头可以抚摸，从袖口向上拖动可以抛星，点手心可以邀她击掌，按住手心约 700 ms 后继续拖动可以引萤。再次触碰举起的手才完成击掌。引萤时需要让光在任一手心附近慢下来并停约半秒。翼、尾巴、鼻尖使用随网格移动的局部触点。翻页从边缘起手，长按空白处进入设置。收到离线、等待确认或异常等新状态时结束当前游戏。下列基础页面手势也用于其他角色。[体验白龙娘](../design/badge-prototype.html)

- 点角色：轻微回应或小心形，持续 900 ms、冷却 3 s。只是本地互动，不修改真实工作状态。
- 左右划：角色主页、使用详情、会话页之间切换。水平位移 > 40 px，且水平位移大于垂直位移的 1.3 倍。
- 上划：主页进入使用详情；下划：返回主页。
- 长按：静止按住 ≥ 700 ms 打开设置；位移 > 12 px 取消长按。识别长按或滑动后，不再触发单击。
- 等待状态下点提示胶囊：发送 open_host 意图，电脑端定位相应会话。不会在徽章上批准命令。
- 会话页点固定按钮：发送 pin_toggle，收到 ack 后更新；无 ack 显示失败。
- 唤醒第一次触摸只唤醒屏幕，不触发底层操作。PWR 保留板卡电源行为，BOOT 首版不承担普通互动。
- 导航立即响应单击。GPT 网页角色会在鼻尖第一次被碰到时皱鼻，在约 820 ms 内再次被碰到时打喷嚏。

优先级：电源故障/连接中断提示 > 等待交互 > 会话阶段 > 宠爱反馈 > 装饰。点角色时保留状态文案；有新的 waiting / error 立即取消低优先级互动。

## AMOLED 与电源体验

默认亮度建议 35%，在用户设置中调节，不对未确认的电池充电参数做写入。闲置 30 s 降亮，120 s 可熄屏；工作中不因没有触摸就完全熄屏，改用更低亮度。需要用户介入时恢复到设定亮度，可受夜间模式约束。

长时间静止的信息每约 60 s 做 1–2 px 微移；停止全亮白底常驻。关闭屏幕前停止不必要动画。唤醒后重建/恢复显示对象应受同一 UI 所有者控制。真正深睡会中断 USB，需要独立定义重连，首版先做屏幕休眠。

目标佩戴与桌面距离不同，G2 用真机在 30–60 cm 看清状态及额度；浏览器放大好看不算通过。
