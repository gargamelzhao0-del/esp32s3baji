# DeepSeek 鲸鱼娘的设备端应用

默认开机画面是晴海、全身、喂白米饭，按网页原有时长从小口进食演到大饭盆。圆屏尺寸为 466×466。应用以检视台的 184×184 Canvas、368×368 CSS 舞台和独立的中文气泡为像素基准。长按圆屏 650 毫秒可在像素与高清模式间切换，两边显示同一个动作或 Agent 状态。[原始检视台](../assets/ai-girls/pixel/deepseek/v1/review.html)

## 触屏操作

| 操作 | 像素圆屏 | 高清角色舞台 |
| --- | --- | --- |
| 点角色中央 | 切换到下一套动画 | 切换到下一套动画对应的高清原画 |
| 点左侧徽章位置 | 依次切换 12 个 Agent 状态 | 依次检视同一组高清状态 |
| 点屏幕上部 | 依次切换晨雾、晴海、灯塔黄昏、荧光夜海 | 开关头心竖线和脚底横线 |
| 点屏幕下部 | 暂停或恢复角色动画 | 暂停或恢复呼吸 |
| 向左 / 右划 | 下一帧 / 上一帧，并暂停；在状态模式下逐项切换 | 检视下一个 / 上一个动作或状态 |
| 向上划 | 切近景 | 打开高清设定图集 |
| 向下划 | 切全身 | 在原比例图集内返回角色舞台 |

图集中点左右两侧切图，点中央放大或还原。放大后可拖动查看细节。四张图分别为特色互动、三视图与拆件、全身备选、十二态校验。完整构图按圆屏内接尺寸展示。

## 两种显示方式

像素动作保留待机呼吸、喂饭、称重、弹呆毛、逗水母和抱枕休眠的全部 54 个网页原画帧。DSK3 在每两个原画之间增加七个角色采样位置，按动作原有节奏分别以 48、56、56、64、56、32 Hz 推进。GPIO13 的 TE 决定屏幕可呈现的时刻，64 Hz 动作在一次扫描中取最新姿势。暂停后的左右划动仍按网页原画逐帧检查。十二种 Agent 姿态分别是待机、思考、读文件、写代码、运行、检索、等确认、完成、出错、限流、压缩、休眠。暂停角色时，云朵气泡继续沿网页的 2.4 秒缓动曲线漂浮。应用从浏览器取 7 个真实位置，再对变化的瓦片插值，把 3 CSS 像素的行程细分成 49 个位置。

高清模式把网页右侧 340×340 舞台居中显示。18 个按钮关联到 17 张不同姿态，待机动画和待机状态共用同一张原画。素材来自 680×680 的透明角色图。正式固件按原网页的 2.8 秒缓动曲线，以浏览器绘制的 17 个呼吸位置为基准，将相邻位置之间小于一个屏幕像素的位移分为八份，往返经过 129 个采样位置。原有位置仍逐像素复现，参考线分别取自浏览器的开关两套画面。设备按当前姿态和可用 PSRAM 缓存解码结果，连续呼吸只发送可能变化的条带。四张图集在 Flash 版中使用原尺寸，三张为 1376×768，一张为 1010×848。[原始高清素材](../assets/ai-girls/normal/deepseek/v1)

通过 USB 装入 RAM 的双模式演示可与设备已有的 Flash 固件共存。这个演示使用相同的像素包、高清静止姿态和手势，按当前姿态预先找出哪些像素可以直接取自角色或背景，屏幕每次扫描时按呼吸曲线选行合成，四张图的最长边为 768 像素。真帧包另可通过 USB 分页送入同一设备画笔做逐帧校验。[RAM 上板步骤](../tests/device/deepseek_review/README.md)

## 构建与验证

```powershell
.\tools\build.ps1                 # 默认双模式鲸鱼娘
.\tools\build.ps1 -Character GPT  # 白龙娘
.\tools\build.ps1 -BoardCheck     # 板级诊断
python components/baji_deepseek/tests/run.py
python components/baji_deepseek_hd/tests/check.py
python tests/deepseek_reference/compare.py
```

像素画面和高清静止姿态随应用镜像发布。高清呼吸真帧位于 `hdmotion.hda` 独立数据分区，构建目录中的 `flash_args` 同时列出引导、应用、分区表和动作包。安装完整版本时须使用这一组文件。重采参考图需要 Python、Pillow、NumPy、Playwright 和 Chrome，主机 C 画笔测试需要 GCC。参照本地页面时可为最后一条命令附加 `--url http://127.0.0.1:8765/pixel/deepseek/v1/review.html`。校验先将网页像素量化为高字节在前的 RGB565，再按物理像素中心映射到 466×466。固件的帧校验覆盖面板输入数据；光学色彩、面板亮度和照片观感属于不同测量。

本轮设备版以提交 `64449fb` 中的角色图、动作参数、DSK2 包和浏览器参考值为基准。重建 DSK3 时，将该版本的 `assets/ai-girls` 作为 `authoring/motion.py --web`，该版本的 `components/baji_deepseek/assets/scene.dsk` 作为 `--anchors` 输入。生成器保留旧锚点的 RGB565 数据。使用本机新版 Chrome 对归档页面重新烘焙，3,696 幅中有 32 幅在晨雾全身待机的云朵位置出现差异；随固件发布的 DSK3 与归档锚点 3,696 幅全部相同。
