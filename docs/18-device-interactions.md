# 圆屏互动触发手册

GPT 白龙娘用额头、脸颊和眼神回应触摸。DeepSeek 鲸鱼娘兼有宠物动作和检视台，可以切姿态、看原画、暂停或逐帧检查。下表描述 466 × 466 圆屏上的行为，坐标从左上角起算。

## GPT 白龙娘

| 触发 | 圆屏效果 |
| --- | --- |
| 开机、摸头播完 | 自动循环待机。 |
| 在当前帧的额头椭圆内按下 | 立即开始摸头，30 张原画按 16 帧/秒播放，约 1.875 秒后回待机。短按在两帧之间松开仍可识别。 |
| 点或按住左、右脸颊 | 相应一侧脸颊被按扁。按住会停留在受压姿态，松手或拖出后继续播放回弹。鼻尖单独排除。 |
| 1.1 秒内轻点脸颊三次，或在脸颊上左右揉动两次换向 | 播放挠痒反应，结束后回到待机。动作期间使用原画的表情和眼神。 |
| 在待机或摸头期间按住圆屏或拖动 | 视线随手指位置在五个横向、三个纵向位置间变化。松手后向当前工作姿态的视线逐步归位。一次长按额头只触发一次摸头。 |
| 收到 Agent 状态 | 下面的状态表驱动图标与眼神。阅读在左下与下方之间移动，写入看右下，运行看右侧，搜索左右扫视。手指按住期间优先跟随手指。 |

额头和脸颊命中区跟随当前显示帧。左右脸与挠痒共包含 222 个显示采样，原画之间的过渡也参与局部刷新。[脸部命中与素材](../components/baji_pet/baji_pet.c) · [互动播放器](../components/baji_pet_app/pet_player.c)

## DeepSeek 鲸鱼娘

默认首屏是晴海、全身、喂饭。点按用按下的位置选区，划动在松手时按主方向执行。横向与纵向距离相等时按横向处理。

| 操作 | 像素圆屏 | 高清舞台 |
| --- | --- | --- |
| 点中央角色区域 | 依次检视待机、喂饭、称重、弹呆毛、逗水母、抱枕打盹。处于姿态检视时返回上次的动作。 | 检视相应高清原画，播放轻微呼吸。 |
| 打盹时按住胸前枕头露出的布面 | 在全身图点左侧外露的蓝白布面，近景点底栏上方的白色枕沿。纹样跟着接触处下陷，松开后约 156 毫秒回弹。 | 高清枕面也会随呼吸和按压变形。在枕头上长按或滑开都由枕头接收，回弹结束后恢复最新 Agent 姿态。 |
| 点左边 | 在左徽章区（`x < 109，172 ≤ y ≤ 271`）切到姿态组，随后逐项检视 12 种姿态。 | 点中段左侧（`104 ≤ y ≤ 362，x < 122`）检视姿态。 |
| 点顶部 | 在 `119 ≤ x ≤ 347，y ≤ 76` 切晨雾、晴海、灯塔黄昏、荧光夜海。 | 在 `y < 104` 开关参考线。 |
| 点底部 | 在 `105 ≤ x ≤ 361，y ≥ 369` 暂停或恢复本地动作；气泡按自己的节奏浮动。 | 在 `y > 362` 暂停或恢复高清呼吸。 |
| 左划 / 右划至少 38 像素 | 动作页前进 / 后退一张原画并暂停；姿态页切换下一 / 上一姿态。 | 在 6 个动作和 12 个姿态之间顺序切换。 |
| 上划 / 下划至少 38 像素 | 上划切近景，下划切全身。 | 从舞台上划进入设定图集，在原比例图集下划退出。 |
| 原地按住至少 650 毫秒 | 在可用时切换像素与高清模式。整个接触期间任一轴位移达到 16 像素就取消长按。 | 同左。切换所用的那次松手不会再执行点按。 |
| 在图集中点按、拖动 | 通过高清模式进入。 | 点中央（`147 ≤ x ≤ 319`）放大或还原，点左右侧或原比例横划切图。放大后拖动平移，拖出去再拖回来仍按拖动处理。 |

选择本地动作后优先展示一个动作周期，手动选的姿态优先展示 1.6 秒，然后恢复最新 Agent 姿态。切换相邻姿态时以按下时可见的项目为准。图集隐藏状态浮层，退出后显示最新状态。[手势仲裁](../components/baji_deepseek/deepseek_controls.c) · [像素动作与热区](../components/baji_deepseek/deepseek_review.c)

十二个检视项依次为待机、思考、阅读、写入、运行、检索、等确认、完成、出错、限流、压缩、休眠。休眠姿态由本地检视触发；抱枕打盹则是六套本地动画之一。

## Agent 怎样触发动作

设备接受完整显示快照。在通用 JSONL 中，`session` 选定会话，`phase` 决定大类，`activity` 细分工作动作，`outcome` 决定终态反馈。屏幕上点出的“阅读”可用于看姿态；电脑端实际开始读文件，需要上游事件进入主机桥。

| 上游输入 | 状态与表现 |
| --- | --- |
| `working/tool`，配 `thinking/reading/writing/running/searching/compact` | 思考、阅读、写入、运行、搜索、压缩。鲸鱼娘换对应姿态；白龙娘改变视线和图标。活动未细分时使用思考。 |
| `waiting`、`error`、`limited` | 分别显示等待、出错、限流。鲸鱼娘对应等确认、失误和疲惫姿态。 |
| `ended`，结果为 `succeeded` 或 `failed` | 成功或失败反馈持续 1.6 秒，随后显示结束或失败。心跳保持同一轮次时不会反复播放。 |
| `ended`，结果未知或取消 | 分别显示结束或取消。Codex 的普通 `turn.completed` 默认归为结果未知。 |
| `session: null`、数据超时 | 前者清除选中会话；连续 8 秒未收到有效快照时显示离线，指标转为未知，保留本地玩法。额度、上下文也各自按有效期独立失效。 |

例如向已配对、正在运行无线固件的热点设备发送一次阅读状态：

```powershell
'{"type":"agent.state","session":"demo","turn":"t1","model":"local-model","phase":"tool","activity":"reading"}' | python tools/agent_sync.py send --wifi http://192.168.4.1
```

Codex 的 `turn.started` 可进入思考，命令执行、文件修改和搜索分别进入运行、写入和搜索。原生事件缺少“正在读文件”“等待批准”或账号额度等信息时，自定义适配器可以显式上报。USB、Wi-Fi 和 BLE 收到并校验完整签名快照后才更新角色。设备上的触摸用于本地表演，回传电脑定位会话的接口尚待实现。[通用格式、配对和完整回放](17-wireless-agent.md)

## 电源反馈

两份固件每 5 秒读取一次 AXP2101。顶部 84 × 24 区域显示电源和可用的电池百分比。插头表示外接供电，闪电表示正在充电。设备能区分 0%、读数未知和无电池；读数丢失时会清除上一次的数值。高清图集隐藏浮层，退出图集即可查看。

## 如何区分网页演示与固件

GPT 网页版仍有长按梳毛、阅读时翻书、空闲后打盹等设备待移植动作。设备端的抱枕按压属于鲸鱼娘的打盹动作。宠物音效、亲密度演化和运行时换角色仍在待开发清单。[网页手势实现](../design/pixel-badge/gestures.js) · [当前功能与验收缺口](07-roadmap-and-acceptance.md#需求到验证的追踪)
