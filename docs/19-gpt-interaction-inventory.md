# GPT 白龙娘圆屏互动清单

**白龙娘也有抱枕打盹。** 在待机时点圆屏正下方的「陪玩」→「打个盹」，或让她安静约 28 秒。等她把云朵枕铺到胸前偏右、两手搭好、脸颊靠下，再按露出的蓝色枕面。按布面可以拍枕，点脸可以叫醒她，两处的反应不同。

本文核对 GPT 网页的动作注册表、手势、自动行为以及设备源码中的入口。下表写的是新版 GPT 固件的操作；某块板是否已装上这版、哪些动作经过真人触摸，见对应版本的验收记录。DeepSeek 鲸鱼娘另有自己的抱枕打盹和高清检视操作。[验收记录](08-validation-log.md) · [鲸鱼娘操作](18-device-interactions.md) · [白龙娘网页原稿与逐帧动图](../design/pixel-badge/README.md)

## 手指能做什么

左右均指面向屏幕的人所看到的方向。请点当前画里的部位，脸、手、书角、泡泡和枕面会随动作移动。菜单从圆屏正下方的「陪玩」打开。进入「小动作」可直接点「左翼」「右翼」「摸尾尖」「碰鼻尖」，也可连续按同一项试出喷嚏或闹别扭。离线时「工作预览」可以切到下表所需姿态，「下一页」可翻到其余姿态。[菜单](../components/baji_pet_app/pet_menu.c) · [设备手势与仲裁](../components/baji_pet_app/pet_interactions.c)

| 玩法 | 怎么触发 | 可核对的反应和分支 |
| --- | --- | --- |
| 左右蹭头 | 轻点相应一侧额头并松开 | 各自朝手歪头蹭。连续点同一侧有约 350 毫秒间隔。 |
| 额头贴贴 | 待机点「伸手」，或空闲约 7 秒等她拨开刘海。把手指停在她送出来的一侧 | 她先理发、等待、眯眼，再把额头贴过来。摸另一侧会找手。中途松手会收回，完全不理她会自己理好刘海。同一段安静时间只主动邀请一次。 |
| 顺毛、送星心 | 在刘海按住约 230 毫秒，或沿头发横向抚摸。额头邀请中也可以直接滑动 | 她随指偏头。待机时连续抚摸，至少两次明显换向，再松手可触发双爪捧心。只按住或小幅抖动看普通收势。 |
| 戳脸、按脸、挠痒 | 点或按住一侧脸颊。1.1 秒内轻点三下，或不松手左右揉、明显换向两次 | 单次为同侧眯眼、脸颊受压，松开才回弹。采样窗口内的第三次轻点或第二次揉动换向触发缩肩笑。鼻尖是独立热区。 |
| 碰鼻、喷嚏 | 点鼻尖，在第一次皱鼻的 0.9 秒内再点一次 | 先追视鼻尖，再吸气、闭眼、缩肩打喷嚏。 |
| 翅膀、尾尖 | 分别轻点左翼、右翼、尾尖 | 两侧翅膀有独立原画，尾巴先躲再绕回来。连续碰同一翼有约 350 毫秒间隔。 |
| 闹别扭、哄好 | 待机时在 5.5 秒内戳尾尖三次。随后喂糖、顺毛、摸头、贴额头或送心 | 闹别扭最多约 6.5 秒。安抚成功转为和好，时间到也会恢复。 |
| 喂星糖、戳糖泡 | 点「喂星糖」。等约 3.3 秒，泡泡浮稳并出现高光，点泡膜或在菜单点「戳泡泡」 | 她接一颗糖。等待时按钮显示「等糖泡」。戳破时泡膜从被戳的一帧散开，小糖星沿弧线落到鼻尖。 |
| 追星萤、接星 | 点「追星」。按住星萤举高、移低、绕过脸，再把它放进任一只可见的手心，或直接点手心 | 眼神和头追星，接近手心时掌边亮起。左右手分别接住、捧起并眨眼。也可用菜单「放手心」代投、「收起星星」退出。 |
| 抛星、失手、再邀 | 朝手心轻甩并松手，也可以故意丢偏。成功后不再摸她 | 有方向和距离判定，失手的星萤会绕回来。成功后安静约 11.5 秒会从另一侧再邀请一次；一直不接，星萤自行飞走，留下原来的打盹机会。 |
| 云朵枕、拍枕 | 待机「打个盹」或持续空闲约 28 秒。按住、松开胸前偏右露出的蓝色枕布 | 铺枕→双手搭枕→脸颊压枕→呼吸、冒 Z。指下布面和花纹会一起陷下、回弹。布面遮罩把脸和手排除在变形范围外。 |
| 偷看、叫醒、再入睡 | 枕头已铺好时点左半或右半角色，再在单眼偷看时点一次。也可在菜单点「轻轻叫她」→「再叫一声」 | 第一次睁对应一只眼，等约 3.1 秒会闭眼继续睡。第二次抬头、收枕、伸懒腰。刚开始点头就被碰到，会坐直。起身中点「回去睡」可等伸展结束后重新伏下。 |
| 看手指 | 待机按住或移动手指，或在追星时移动星萤 | 玩家手指与星萤各有自己的视线目标。网页用鼠标悬停也可引起注意，圆屏靠实际接触。喷嚏、睡眠、眨眼的闭眼原画应保持闭眼。 |

## 工作时可以陪她做什么

离线预览从「陪玩」→「工作预览」进入。有真实快照时，角色以所选 Agent 会话为准。菜单会把当前能用的道具直接写成「翻一页」「敲亮键」「找星屑」或「碰一碰手」。其余工作姿态可试「顺顺毛」或直接戳脸。新的 Agent 状态可以打断陪玩、收枕或换道具。同一发布流中切换选中身份时，即便前后都为阅读也要重新开始；同一身份的心跳会保留当前进度。上游的身份范围由会话、轮次和模型等共同决定。[无线 Agent](17-wireless-agent.md) · [主机身份定义](../host/baji_bridge/state.py) · [设备投影](../components/baji_agent/agent_sync.c)

| 姿态或事件 | 看什么、点哪里 |
| --- | --- |
| 待机 `idle` | 呼吸、眨眼、尾尖晃动，常规陪玩及安静邀请从这里开始。 |
| 思考 `working` | 托爪、斜向上看，配灯泡状态标记。 |
| 阅读 `reading`、月页 `readingMoon` | 从星月图鉴右角向左拖。轻点书角或拖过约 58% 的翻页进度松手，翻到另一页。拖开一小段后松手，折角弹回，她偷看一眼，保留原页。星页、月页各有翻页和偷看动作。 |
| 执行 `running` | 点手上口袋终端右端的亮键。她用两次落指回应，再眨一下眼。 |
| 写入 `writing` | 一手托环装手帐，一手用羽笔画猫脸。点脸、摸头或顺毛可观察工作道具与回应如何衔接。 |
| 搜索 `searching` | 点黄铜放大镜的镜片。她把镜心对准眼睛，镜沿亮起星屑。 |
| 等确认 `waiting` | 点举起的手，和她击掌。屏上继续显示等待，实际批准操作在电脑端完成。 |
| 整理上下文 `compact` | 三张带彩色索引的纸签从错开到叠齐。可在整理时尝试按脸。 |
| 完成 `succeeded` | 完成时张开双翼庆祝，配成功标记。 |
| 本轮结束 `ended` | 放下工作、松气，配休息标记。 |
| 异常 `error` | 缩翼、紧张表情和告警标记。设备的异常或失败提示使用这一组原画。 |
| 受限 `limited` | 翅膀放低、疲倦叹气，配限流标记。 |
| 取消 `cancelled` | 收起道具、等待下次开工，配取消标记。 |

网页还有配对道具原画。摸头、顺毛、碰鼻、戳脸、挠痒及碰翼尾，会根据当前道具选择能衔接的动作；需要腾手时使用收纳动画。这里要分别验收“换图时手中仍有道具”和“恢复书页、笔尖或纸签的原有进度”。两者仅看动作名称无法分辨。[网页道具衔接](../design/pixel-badge/app.js) · [设备帧与命中接口](../components/baji_pet_clips/include/baji_pet_clips.h)

## 哪些反应要等条件满足

| 类别 | 网页设计的条件 | 设备核对项 |
| --- | --- | --- |
| 自主微动作 | 安静时择机向左或向右张望、向两侧理发、伸懒腰、哼歌、打哈欠、摆尾、分别抖翼、皱鼻、喷嚏、递星心。按住或睡着会让出时间。 | 候选动作与手势播放分开检查。哼歌需要亲密度 ≥10，主动送心需要 ≥25，手动顺毛送心可直接触发。 |
| 亲密度 | 有效互动累积到 100。五档为初见、好奇、亲近、黏人、默契，分界为 0、10、25、50、75。 | 检查一次有效互动只加一次，及重启后读回亲密度。 |
| 眼神、脸红、浮记 | 皱鼻有问号，摸头有心，挠痒或哼歌有音符，翼尾有星屑，闹别扭有怒记。网页还有重逢星眸、高亲密度脸红、状态汗滴、气泡亮边、接星掌光和收指星光。 | 固件分别使用逐帧角色、部位锚点和局部动态绘制。枕布必须响应指下位置，手和脸须留在上层；星萤须跟随触点，而非在固定位置播放。 |
| 重逢、情绪、调度 | 网页重开时，距上次保存至少 15 分钟可有约 4.2 秒重逢。精力、好奇、亲昵和昼夜影响呼吸与微动作权重。闹别扭中有两次偷瞄窗口。 | 设备以本次开机内相隔 15 分钟的互动触发重逢。连续通电时，精力、好奇和亲昵参与选取微动作。亲密度和声音开关写进 NVS，跨断电离开时长和网页昼夜调度没有持久化。 |
| 声音 | 摸头、顺毛、贴额头、戳脸、挠痒、碰鼻/喷嚏、喂糖/戳泡、翼尾、击掌、击键、镜片、翻页、星萤、送心、闹别扭/和好以及睡眠、偷看、醒来、拍枕。等待、完成、结束、异常、受限也有音色。 | 用「陪玩」→「声 开／关」切换。声音由同一份网页音符生成，38 个事件共享 26 段旋律。拍枕在放手时发声，静音时照常响应触摸。 |
| 遥测和电源 | 网页分别标注模拟、实时、回放、结束、离线、连接中。第一个额度窗口显示剩余百分比，上下文显示已用百分比。 | 通用 Agent 快照负责状态和指标。估算、有数值的 0%、未提供、已过期要能区分；连续 8 秒没有有效快照转离线。设备电池/充电来自 AXP2101。 |
| 网页观察选项 | 网页有全身/近景、网格、昼夜四种天空及自动、0–2 只纸鹤、对白文字、系统减少动效、网页时钟、键盘替代操作和角色切换。 | GPT 设备素材采用近景、像素网格、黄昏天色。这些网页设置和对白面板没有设备菜单入口。鲸鱼娘的高清图集在其独立固件中。 |

网页 `actions` 中 32 个名称与 `states` 中 13 个名称均能在固件素材索引中找到。网页还保留旧的 `play` 单段原画。现行「逗星萤」分派到 `starWatch`、左右接星和飞行状态机，成功、抛偏及安静后再邀应分别检查。自动理发和张望则由动作导演调度，未出现在网页动作按钮里。[动作注册、输入与状态抢占](../design/pixel-badge/app.js) · [固件素材生成](../components/baji_pet_clips/authoring/bake.py) · [自动动作与性格](../design/pixel-badge/motion.js) · [表情与眼神](../design/pixel-badge/face-fx.js) · [音效映射](../design/pixel-badge/sound.js)

## 可复查的验证

2026-11-24，COM21 上的 QA 固件完成 31 步注入触点回放。板端记录到枕面按下和松开、右眼偷看后叫醒、戳破糖泡、右手接星、星页翻书、闹别扭和喷嚏。ES8311 读回芯片 ID `8311` 和音量寄存器 `A8`，并完成首段 16 kHz 短音发送。该轮验收使用程序输入，真人手感与这批旋律的听感需要现场确认。[设备验收记录](08-validation-log.md)

从仓库根目录可复查网页的 51 项行为测试。固件手势回归直接读取设备素材包，检查输入、状态变化、部位遮罩和亲密度解锁。特效回归按整屏、按局部逐扫描行绘制 54 组状态，比较每个 RGB565 像素并检查手部遮挡。声音回归按网页谱面重建资产，并在主机上检查播放、抢占、静音、读回已保存设置及设备缺失时的行为。[网页测试](../design/pixel-badge/authoring/) · [固件手势回归](../components/baji_pet_app/tests/run_interactions.py) · [特效回归](../components/baji_pet_app/tests/check_effects.py) · [声音与存储回归](../components/baji_pet_app/tests/check_feedback.py)
