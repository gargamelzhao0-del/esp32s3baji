# 固件像素角色

白龙娘的待机和摸头动作以每秒 48 个姿势样本播放，共用 466 × 466 实际圆屏的全身取景。待机的 43 个原画姿势扩展为 172 个样本，一轮 43/12 秒（约 3.583 秒）。摸头的 30 个原画姿势扩展为 90 个样本，时长 1.875 秒。每个原画姿势与其五档水平、三档垂直视线保持网页 RGB565 像素。脸部、头发和手部轮廓的过渡在原生 138 × 132 精灵上离线生成。黄昏背景与像素网格由圆屏模式渲染，型号、状态、额度和上下文由设备在角色轮廓外绘制。额头可点区域跟随当前姿势。

BPH6 资源包占 1,428,079 字节，解压后的表占 3,400,826 字节。它保存原生像素在相邻姿势间的变化。每个原生像素由四个 RGB565 采样表示，保留网格纹理。固件顺序读取变化像素的坐标和颜色编号，按预计算的局部窗口提交。在前一条 DMA 传输期间，下一条用到的像素行展开到物理帧缓冲区。每个姿势分别保存到待机和摸头入口的像素差集，点按触发摸头或动作结束返回待机时，仅替换实际变化的原生像素。任意跳转可从最近的关键帧恢复。活动画面占 434,312 字节，三个原生索引面合计 203,136 字节，内部 RAM 调色板占 19,832 字节。原版近景 BPH5/BPR1 与 BPT1、BPT2 压缩资源仍可通过同一接口播放。

角色绘制器依赖公共像素矩形和 RGB565 条带约定。由一个显示任务依次选择姿势、渲染条带，将已经提交的状态保留到整次绘制成功。角色公共头可由 C 或 C++ 应用直接引用。[角色接口](include/baji_pet.h) · [像素矩形与条带约定](../baji_graphics/include/baji_graphics.h)

## 戳脸与挠痒

离线及无线版 GPT 使用同一套触控映射。点左右脸颊各有独立的压脸、眯眼和回弹动画。按住会停在脸颊压紧的位置，抬手从该帧继续。每次轻点短于 420 ms、1.1 秒内点三次，或按住脸颊小幅横向揉动、改变方向两次，均触发挠痒笑。向外大幅拖动会解除压脸。脸颊热点跟随动作的鼻尖和脸部方向，排除鼻尖中央。

三段动作与常速互动使用同一份全身图集。左右脸各 22 张原画，挠痒笑 30 张，16 Hz 原画扩展至 222 个 48 Hz 样本。每个样本保存角色的原画眼神。额头与待机仍支持实时二维凝视。独立的 `assets/reactions.bpr` 占 2,772,172 字节，直接从 flash 读取变化像素和局部刷新窗口，复用 BPH6 的帧缓冲与工作区。跨动作切换可从每 12 个样本保存的关键帧重建。

## 构建与复核

正常固件直接嵌入已生成的 `assets/motion.bpz` 和 `assets/reactions.bpr`，编译仅需 ESP-IDF。将 CMake 变量 `BAJI_PET_EXTERNAL_ASSET` 设为 `ON` 时，调用方可通过 `baji_pet_open_data` 提供同一份压缩资源，函数返回后调用方即可释放输入。如需外部加载戳脸与挠痒，使用 `baji_pet_attach_reactions` 绑定一份四字节对齐、在播放器整个生命周期内有效的 BPR2 数据。只加载 BPH6 时仍可使用待机与摸头。

生产固件把戳脸与挠痒资源放在四字节对齐的只读 flash 区段。成功绑定时打印 `reactions.bpr active`。若该资源校验失败，会记录一条 `reactions.bpr rejected` 警告，继续播放已经加载的待机、凝视和摸头。基础动作资源校验失败时，启动入口返回错误。显式调用 `baji_pet_attach_reactions` 的外部播放器可直接读取该次绑定的错误码。

如需重新生成素材，安装 Python、Pillow、NumPy、opencv-python-headless、Playwright 和 Chromium，在仓库根目录运行以下命令。

```sh
python components/baji_pet/authoring/bake_motion.py
python components/baji_pet/authoring/bake_reactions.py
python components/baji_pet/tests/run.py
```

高刷与常速导出器共用 `authoring/panel-reference.zip`，其中保留源图集的全身像素、抱枕前景、锚点、绘制脚本及原作者声明。从本仓库即可重建两个播放路径。用 `python components/baji_pet/authoring/panel_source.py design/pixel-badge` 更新该参考。原版 BPT 的近景复核仍使用独立的 `authoring/reference.zip`。

原版锚点导出器 `authoring/bake.py` 的 `--web design/pixel-badge` 选项改用当前工作区的网页与角色图集。对于原始网页渲染器，导出器在图集写入画布后插入跟随面部锚点的凝视层；带有 FaceFX 的版本调用网页自有的眼部绘制。更新锁定参考时显式加上 `--freeze-reference`。脚本检查每个睁眼姿势的目光确实变化、闭眼期间没有新增瞳孔。

`tests/web.crc` 包含直接取自浏览器最终 466 × 466 画面的 1,095 个 RGB565 校验值。`tests/motion.crc` 对应 3,930 个完整姿势与视线组合。宿主测试使用 GCC 或 Clang 编译生产绘制器，分别以整屏和局部窗口组成同一画面，覆盖循环、跳帧、触摸中断及单像素裁剪。角色与字体署名应随固件和素材分发。[素材与授权](assets/CREDITS.txt)
