# GPT 白龙娘动作资源

`assets/clips.bpc` 包含白龙娘的 65 个网页动作、78 个手持工作道具场景变体，以及赌气、赌气偷看、重逢和高亲密脸红四种待机表情，共 4,445 帧。完整的 138 × 132 全身精灵绘制在 184 × 184 的舞台上，保留两倍 LCD 网格，经最近邻采样输出至整块 466 × 466 圆屏。抱枕、枕前的双手和脸颊，以及两枚睡眠 Z，均取自网页实际分层合成后的画面。

动作名与 `PIXEL_CLIPS` 一致。`pet_clips_lookup(bank, "pat", "reading")` 优先选中持书动作。`pet_clips_select` 给出半开像素更新矩形。`pet_clip_hit` 按当前画面读取额头、脸、鼻、两翼、尾巴和道具的位置。枕面有独立遮挡掩码，点在覆盖枕头的手上时仍可触发身体动作。键盘、放大镜和书页的点击是否生效由动作状态机决定。

资源捕获采用黄昏全身视图和静止视线。运行时视线、高刷摸头、实时 Agent 信息、星萤、糖泡破裂粒子、触点及按压反馈由应用层合成。书写、整理过程中切换其他动作时，暂停的手和收纸动作使用该工作的第 0 帧纸面；网页还能保留被打断时的那一笔和纸纹。

## 运行和校验

运行预构建资源只需要本仓库。固件从 `hdmotion` 读取包，启动时检查取景版本、长度、目录与 CRC32。新固件遇到旧近景分区会退回内置的全身高刷动作。每十二帧保存一个独立关键帧，中间帧存储局部网格颜色索引的异或差分。设备在 PSRAM 中保留目录、本帧网格与解压工作区，按需从 Flash 读取单帧或枕面命中掩码。

从工程根目录执行以下测试，需要 GCC、Python 和 NumPy。测试运行实际 C 解码器，以 RAM 模拟分区读操作并复用主机 zlib 实现。依次应用所有帧的更新矩形，与 Chromium 独立缩放并转换的整屏 RGB565 校验值比较，并覆盖随机跳转、重复选帧、破损包和枕面触摸。

```
python components/baji_pet_clips/tests/run.py
```

圆屏边界回归还需要 Pillow、Playwright 和 Chromium。测试移动角色与特效到四边及对角，检查真圆内全部物理像素，并将全部全身姿势与屏幕、上下仪表和原始图块的边界对照。

```
python components/baji_pet_clips/tests/round_stage.py
```

运行以下命令从同仓库锁定的全身图源重新烘焙，生成动作分区、浏览器校验值和 `authoring/web-inputs.sha256`。用 `--web` 可以试验工作区的其他原画。

```
python components/baji_pet_clips/authoring/bake.py
```
