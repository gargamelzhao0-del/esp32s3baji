# GPT 白龙娘动作资源

`assets/clips.bpc` 包含白龙娘的 65 个网页动作、78 个手持工作道具场景变体，以及赌气、赌气偷看、重逢和高亲密脸红四种待机表情，共 4,445 帧。近景使用网页的 184 × 184 原生画布和两倍 LCD 网格，最终按最近邻采样输出 466 × 466 RGB565。抱枕、枕前的双手和脸颊，以及两枚睡眠 Z，均取自网页实际分层合成后的画面。

动作名与 `PIXEL_CLIPS` 一致。`pet_clips_lookup(bank, "pat", "reading")` 优先选中持书动作。`pet_clips_select` 给出半开像素更新矩形。`pet_clip_hit` 按当前画面读取额头、脸、鼻、两翼、尾巴和道具的位置。枕面有独立遮挡掩码，点在覆盖枕头的手上时仍可触发身体动作。键盘、放大镜和书页的点击是否生效由动作状态机决定。

资源捕获采用黄昏、近景、静止视线和离线 HUD。运行时视线、高刷摸头、实时 Agent 信息、星萤、糖泡破裂粒子、触点及按压反馈由应用层合成。书写、整理过程中切换其他动作时，暂停的手和收纸动作使用该工作的第 0 帧纸面；网页还能保留被打断时的那一笔和纸纹。

## 运行和校验

运行预构建资源只需要本仓库。固件从 `hdmotion` 读取包，启动时检查长度、目录与 CRC32。每十二帧保存一个独立关键帧，中间帧存储局部网格颜色索引的异或差分。设备在 PSRAM 中保留目录、本帧网格与解压工作区，按需从 Flash 读取单帧或枕面命中掩码。

从工程根目录执行以下测试，需要 GCC、Python 和 NumPy。测试运行实际 C 解码器，以 RAM 模拟分区读操作并复用主机 zlib 实现。依次应用所有帧的更新矩形，与 Chromium 独立缩放并转换的整屏 RGB565 校验值比较，并覆盖随机跳转、重复选帧、破损包和枕面触摸。

```
python components/baji_pet_clips/tests/run.py
```

重新烘焙还需要 Playwright、Chromium / Chrome 及原型工作区 `design/pixel-badge`。用 `--web` 可指定其他源目录。原型包含本次工作树中的设计修改，单独检出固件代码时可运行上面的全部基准测试；要重新得到相同图像，请按 `authoring/web-inputs.sha256` 确认原型脚本和图集版本。重新烘焙会同时更新预构建资源、浏览器基准和源文件清单。

```
python components/baji_pet_clips/authoring/bake.py --web design/pixel-badge
```
