# 星屑小屋 · 动作导演 v2

目标：在不改人物形象的前提下，把白龙娘从“会播放片段”变成“像有自己节奏的小家伙”。
这份文档定义动作语言、优先级、微动作、情绪层和可回退方案；实现见 `motion.js`、
`app.js` 中的 `director` 接线，以及 `display.js` 的表情层。

## 1. 她是谁

- 好奇：你一动，她先看；你停手，她会自己补半拍。
- 黏人但要面子：想被摸，会先假装理头发；被摸舒服了，会闭眼靠过来。
- 工作时有小骄傲：做完会抬眼看你，出错会先缩翅膀再看你。
- 容易分心：长时间待机会看尾巴、抖翅膀、打哈欠、哼歌、打盹。
- 不装作知道：Agent 成功/失败只由数据触发，不用“可爱动作”伪造状态。

“活人感”不靠更多帧，而靠八条规则：

1. 永远不要完全静止超过 2.5 秒：呼吸、眨眼、视线的微小变化必须一直在。
2. 先看后动：反应前给 1 拍“注意到”，眼睛先到，头和身体后到。
3. 动完有余势：发梢、流苏、尾巴、呼吸比主动作晚半拍收回。
4. 不同状态不同呼吸：待机慢，工作快，等待屏息，异常短促，受限长叹。
5. 不对称：先动一侧眼睛/翅膀/手，避免左右同时对称。
6. 被打断要记得：暂停当前工作帧，回应完从原帧继续，不从头再来。
7. 心情有惯性：一次互动会改变接下来几秒的微动作和表情。
8. 可打断、可恢复、可回退：任何新 Agent 状态都能压过本地表演。

## 2. 分层

| 层 | 内容 | 谁负责 |
| --- | --- | --- |
| L0 环境 | 夜色闪烁、呼吸位移 | `display.js` |
| L1 基础 | Agent 状态循环（idle/working/reading/...） | `app.js` + 烘焙片段 |
| L2 微动作 | 待机小动作、看人、理毛、伸懒腰、哼歌 | `motion.js` + 片段 |
| L3 反应 | 摸头、戳脸、碰鼻、尾巴、翅膀、喂糖、接星 | `gestures.js` + 片段 |
| L4 反馈 | 接触处的短时表情、圆屏留白处的常驻 Agent 图标 | `display.js` |
| L5 玩具 | 星萤、额头邀请、接触点标记 | `star-game.js` / `forehead-invite.js` |

优先级：

```text
Agent 状态/会话切换
  > 当前 Agent 状态的可见性
  > 用户互动反应
  > 待机微动作
  > idle 循环
```

用户互动可以短暂接管人物动作。只要 Agent 仍有任务、等待或结束信号，顶部状态码和相应图标始终跟随 `desired`。例如，等确认时击掌仍显示 `WAIT` 和回车对话框，摸手不会提交确认。互动结束后回到原状态，工作状态从暂停帧继续。

## 3. 状态反应

| 状态 | 进入 | 循环中的小动作 | 退出/余势 |
| --- | --- | --- | --- |
| idle | 眼睛先回到你这边 | 3.8–7.2 s 一次微动作；7 s 后额头邀请；28 s 打盹 | 被摸时先看你，再回应 |
| working | 托爪、视线斜上 | 金色灯泡，思考时偶尔亮一下 | 有新状态立即让位 |
| reading | 摊书、视线沿页移动 | 翻页高光；每 8–14 s 抬头看你一眼 | 被摸时爪子压住当前页 |
| running | 托终端、敲亮键 | 敲击音符；每 3 s 一次轻微前倾 | 手指停在最后一个键 |
| writing | 摊本、落笔 | 笔迹星屑；每 6–10 s 抬眼 | 笔停在当前笔画 |
| searching | 举镜、凑近 | 镜沿星屑；找到时“！” | 镜片慢慢放下 |
| waiting | 举手、看你 | 带回车箭头的青色对话框 | 击掌后仍保持等待 |
| succeeded | 双跳、张翼 | 带勾的绿色绶带奖章 | 落地回弹后奖章仍可见 |
| ended | 放松、舒气 | 淡紫色收工旗 | 本次工作结束，旗子保持到状态更新 |
| error | 缩翼、抬头 | 带叹号的珊瑚色三角警示牌，偶尔冒一滴汗 | 状态更新后收起警示牌 |
| limited | 垂翼、长叹 | 琥珀色斜纹路障 | 限制解除后随新状态切换 |
| compact | 收纸、对齐 | 纸角星屑 | 回 idle |
| cancelled | 收手、停笔 | 带方形停止键的珊瑚色八角牌 | 保留到状态更新 |
| offline / sync | 顶部显示 `OFF` / `SYNC` | 收起上一会话的 Agent 图标，本地陪玩仍可用 | 收到当前会话状态后重新显示 |

七枚图标的点阵均在 13×13 原生像素内，通过外轮廓和内部符号区分状态。全身视图放在左上方，近景放在左侧。追随糖泡的偏移镜头改用右上方，给跟随镜头移动的头发留出空间。图标绘制在人物后方。状态切换时图标会短暂提亮，思考中的灯泡偶尔再亮一下。减少动效及 `?motion=legacy` 使用相同的静态轮廓。

## 4. 待机微动作

新增烘焙片段（`poses.js` + `bake.py`）：

| id | 帧数 | 内容 | 用途 |
| --- | --- | --- | --- |
| idleLookLeft / idleLookRight | 10 @12 fps | 眼睛先转，头/刘海后到，尾尖跟一下 | 看人、看声音、随机张望 |
| idleGroomLeft / idleGroomRight | 30 @18 fps | 从外侧接近鬓发，手指顺着发束下梳，再收回 | 空闲时整理头发 |
| idleStretch | 28 @16 fps | 两手先后向外舒展，龙翼随手臂打开、回落 | 久坐后伸懒腰 |
| idleHum | 14 @12 fps | 闭眼、轻晃、尾巴打拍子 | 心情好、被摸后 |
| idleYawn | 24 @14 fps | 一手抬到唇边，打完哈欠才放下 | 久待机、睡前 |

复用片段：

- `tail` / `wing` / `wingLeft`：尾巴、翅膀的小反应；用于随机微动作和触碰。
- `nose` / `sneeze`：皱鼻、打喷嚏；低权重，避免重复。
- `heartHug`：高亲密度才解锁的送心。
- `doze` 把云朵枕铺在胸前偏右，两手掌心向下搭好，侧脸落入枕沿。`peek` 抬眼时只释放枕面上缘的压力。`wake` 先抬头收枕，双手空出来再伸展。工作事件中断时，顶栏先更新，人物从正在显示的姿势收枕。[云朵枕打盹实录](authoring/nap-chest-rest.webp)

调度规则：

- idle 下每 3.8–7.2 s 选一个；同一动作不连续出现；最近 8 s 内用过的权重减半。
- 互动后 2.6–4.4 s 不排微动作；指针按住、额头邀请、星萤、传输、打盹时暂停。
- 按图集真实帧数和帧率选择来得及播完的动作。自主动作继续累计安静时间，让出约 7 秒的首次邀摸、11.5 秒的星萤再邀和 28 秒的打盹。
- 减少动效模式下不播放微动作，只保留静态表情和文字反馈。
- 微动作只改变 `active`，不改变 `desired`；结束后回到 `baseClip()`。

## 5. 互动语法

| 操作 | 反应 | 亲密度 | 表情 | 备注 |
| --- | --- | --- | --- | --- |
| 点头/摸头 | pat / patLeft | +2 | 心/星 | 连续 3 次内出心 |
| 顺刘海 | brush | +3 | 星屑 | 两次换向送心 |
| 戳脸 | cheek | +1 | 脸红 | 连续 3 次/两次换向变 tickle |
| 挠痒 | tickle | +3 | 音符/心 | 笑完偷看 |
| 碰鼻 | nose | +1 | 问号 | 900 ms 内再碰变 sneeze |
| 打喷嚏 | sneeze | +1 | 第 14–20 帧鼻旁呼出一小团白气 | 睁眼后白气消散 |
| 碰翅/尾 | wing / tail | +1 | 星 | 先躲再回看 |
| 喂糖 | feed → bubblePop | +2/+1 | 糖果星 | 泡泡位置来自烘焙 |
| 击掌 | palmTap | +2 | 星/心 | 保留等待状态码和回车对话框 |
| 敲键/找星屑 | keyChime / lensFind | +1 | 音符/星 | 工作状态内完成 |
| 接星萤 | starCatchLeft/Right | +3 | 心 | 失败会绕回 |
| 送心 | heartHug | +4 | 心 | 高亲密度更常出现 |
| 额头贴贴 | browInvite | +3 | 脸红 | 现有邀请系统 |
| 翻页 | turnStar/turnMoon | +1 | 星 | 提交页才计数 |

亲密度等级：0–9 初见，10–24 好奇，25–49 亲近，50–74 黏人，75+ 默契。
等级影响：微动作权重、送心概率、被摸时闭眼比例、看向你的频率。数值只存在本机
`localStorage`，不上传；设置页只显示一句“她记得你”。

## 6. 表情层

全部用现有 184×184 网格上的像素绘制，不改人物图：

| 表情 | 形状 | 出现 |
| --- | --- | --- |
| heart | 5×5 / 9×8 像素心 | 摸头、接星、送心 |
| sparkle | 十字星 | 顺毛、翻页、镜沿反光 |
| question | 3×5 `?` | 皱鼻子、碰鼻 |
| ellipsis | 三个像素点 | 打哈欠 |
| sweat | 2×4 汗滴 | 异常、被吓到 |
| note | 3×5 音符 | 挠痒、敲键 |
| blush | 两条 4×1 粉线 | 贴贴、被夸 |

表情有 600–1600 ms 生命；像素向上飘 1–3 px 后消失；减少动效时原地静止。

## 7. 节奏

- 待机和等待使用各自烘焙的呼吸姿态，角色图像、掌心与触点共用一套坐标。
- 眨眼：沿用烘焙循环里的眨眼；新增微动作里也会自然眨眼。
- 反应：接触点标记立即出现；动作片段按烘焙 fps；结束后 200–350 ms 回呼吸。
- 状态切换：保留当前硬切，但在切换前允许 1 帧“注意到”的表情；不做全屏淡入，
  避免像素糊化。
- 互动冷却：同一部位 350 ms 内不重复触发；全局反应 120 ms 内不叠加。

## 8. 减少动效

- 关闭微动作、呼吸位移、漂浮表情；保留一次性的静态表情和文字。
- 额头邀请、星萤、击掌、翻页仍可用，但改用静止关键帧和手动触发。
- 保留顶部状态码及七枚静态 Agent 图标，停止图标的短时提亮。

## 10. 验收

- 待机 10 s 内至少出现 1 次微动作；连续采样已观察到 `nose` 与 `wingLeft`。
- 60 s 清醒窗口内至少 4 次不同微动作，且没有连续重复。
- 在圆屏两种取景下检查七枚 Agent 图标的单色轮廓。等待时击掌、工作时触碰道具仍显示原状态码。切到离线或会话同步时，上一状态的图标随即收起。
- 摸头/顺毛/戳脸/鼻/翅/尾/喂糖/击掌/接星各有不同的表情反馈。
- 打断阅读/写入后，回应结束回到原来的帧，不从头开始。
- `node --test`：motion 逻辑、现有 28 项像素互动用例全绿。
- Chrome 实机页面无 console error；减少动效和 `?motion=legacy` 都可运行。
