# 白龙娘互动动作设计评审

看动作时先遮住按钮和文字，观察她为什么动、身体的哪一处先接触物体、被打断的那一帧里两只手还拿着什么。全身取景用来判断动作来源和重心，近景用来判断眼神、手指及衣料的前后关系。以下帧号从 0 起计，距离使用 184 × 184 圆屏的原生像素。

## 陪玩与工作动作的第二轮复核

用同一段输入在修改前后的网页播放器上重放。全身用鼠标，近景用模拟触屏。星萤落空后每 20 毫秒采样一次，按压痕每 40 毫秒采样一次；糖泡泡和放大镜按各自的原画帧率采样。对照动画中左右同步半速播放，每段首尾有短暂停留。[近景前后对照动画](interaction-replay.webp)

## 胸前偏右的云朵枕

“右侧”按面向圆屏的人所见确定。冰蓝色的云朵枕在胸前向右铺开，外侧绣有一枚淡金色月牙。肩肘先送出双手，手背朝上搭入枕面，头稍晚低下来。熟睡时一侧脸颊压低云形上缘，露在外侧的枕瓣仍鼓着。偷看时枕面稍稍回弹，双手继续搭在原处。[本版与上版同速实录](nap-chest-rest.webp)

逐帧读取最终圆屏，整段熟睡期间可见枕面的中心在胸口中轴右侧至少 20.7 格（全身）和 29.9 格（近景）。两只手腕距最近侧边均至少有 22% 的枕宽，两只袖子都能从手腕连续追到枕头外。在全身和近景中，右侧脸颊分别有至少 9 列、8 列连续像素贴近枕沿，闭眼线保留完整。五段入睡、偷看与叫醒动作共 125 个帧位在每种取景各检查一次。[云朵枕像素与输入检查](nap_prop_check.py)

## 此前抱枕版的打盹评审

旧版全身第 5 帧已经出现 275 个枕面像素，第 7 帧能看到完整的 580 个像素。第 7 到 11 帧，它的左缘从第 138 列滑到第 107 列。此时双手仍在裙腰，画面里找不到递枕的人或托住它的手。偷看时枕头的位置又跟着鼻尖一起升高，脸与布料之间没有卸力的瞬间。上一版的亮度和点击检查都能通过，合起来看却像脸侧挂了个饰品。[同一时间点的全身和近景实录](nap-cradle-review.webp)

| 画面 | 本版的动作设计 | 逐帧验收点 |
| --- | --- | --- |
| 入睡 0–7 帧 | 她低眼找袖边的折角，右手往左靠，露出的布还很窄 | 最初露出的布贴着手，没有完整枕头横穿天空 |
| 入睡 8–14 帧 | 双手分开，把枕面撑开。头稍晚才向画面右侧偏，下巴接近上缘 | 枕角跟随两腕。袖口位于布后，包住枕角的指尖画在布前，嘴和眼睛保持可见 |
| 熟睡 15–34 帧 | 下巴在偏右的一侧压出浅凹，枕腹垂在两手之间。Z 出现在左侧暗空 | 每帧两只手均遮住一部分枕面。普通模式按枕能产生局部形变，按住后滑到脸上不会误叫醒 |
| 左右偷看各 9 帧 | 睁一只眼，头稍抬，枕沿恢复一点厚度，双手继续抱着 | 相对熟睡首帧，偷看期间枕底定位变化不超过 1.5 格；上下两层在相同位置对齐 |
| 左右醒来各 36 帧 | 先抬头卸力，再把两角收回袖边。双手空出以后，翅膀和手臂才先后舒展 | 第 6 帧头已抬起，枕面仍展开。第 18 帧起画面已无枕布，伸展时手上没有残留 |
| 中途收到工作事件 | 顶栏先更新，当前画面里的双手接着把枕头收起，再拿新道具 | 在真实桥接事件回放中，所测熟睡、偷看、醒来中段分别用 480、560、300 毫秒收枕。阅读紧接等待时，已被替换的书不会闪现 |

五段睡眠动作在每种取景有 125 张不同帧位。逐帧将最终合成的布色与握指遮挡对照，布面离嘴部定位点最近仍有全身 4.0 格、近景 4.5 格。鼠标和触屏的初始命中只认露出的布面，布沿因按压从指尖下沉时，原地松手仍算拍枕。直接打开本地 HTML 和通过 HTTP 预览两条入口均已验证。[像素与输入检查](nap_prop_check.py) · [收枕交接检查](nap_handoff_check.py)

## 上一轮其他互动的判定

| 动作族 | 评审与处理 |
| --- | --- |
| 喂糖、等泡泡、点破 | 复核能点破的首帧、提示高光和近景跟拍。泡泡出现以前仍是糖按钮，进入可点阶段后，高光像素落在真实触区。 |
| 逗星、选手、空掌、落空再接 | 原先键盘选远手时，星萤会在一个画面跨过全身约 76 格、近景约 100 格。如今她先看着星沿袖侧下降，再从下巴下方移向另一只手。20 毫秒采样中最大步幅分别为 8.62 和 7.86 格。按空掌会亮起对应手心，滑出就熄灭。 |
| 鼻尖与喷嚏 | 原先叹号从点击时开始淡出，闭眼发力时已经很弱。改为在第 14–20 帧从鼻旁呼出一小团白气，第 15 帧正好闭眼发力。减少动态模式保留这个姿势。 |
| 戳脸与揉脸 | 两次换向揉出笑和连续轻点原有不同反馈。现在两种入口各结算一次大笑、音符和亲密度。保留按住一侧脸颊、松手回弹的前后顺序。 |
| 额头邀请、轻点左右、顺毛、回蹭与送心 | 核对她先送出一侧刘海、等指尖、接触后合眼，以及中途松手的退回姿势。高光贴在额头触区，顺毛期间不重新要求第二次按下。 |
| 翅膀、尾尖、自主理发、哈欠、伸懒腰等待机动作 | 复核两种取景的地标及身体接缝。靠脸的手被打断时要先从正在显示的帧撤回。全身可见尾尖，近景仍有裁切。 |
| 阅读与翻页 | 旧版把拖动距离线性映射为时间，页边实际走的是弧线。同一段近景拖动，旧页边比指尖超前 12.7 格，现在误差 1.1 格。点击自动翻页按原生 16 fps 走完 25 张图，旧版同样的 20 毫秒采样只看到 14 张。 |
| 写入、整理和换工作 | 过去第 47 帧猫脸已经画好，一换状态却露出白纸；第 24 帧已收齐的纸签也会突然摊开。如今猫脸、加完装饰的猫脸、齐边的纸签都接入匹配的收纳姿态。更早的半笔和半叠阶段仍使用通用收纳，强制切走时可能丢失这部分视觉进度。 |
| 执行终端、搜索镜、等待击掌 | 复核指尖碰键后键帽才下沉、镜心对准当帧的眼睛，以及碰掌后 WAIT 与等待标记持续可见。 |
| 思考、成功、结束、取消、受限、异常 | 检查状态轮廓、顶栏和会话切走后的清理。减少动态模式仍能辨识状态。 |
