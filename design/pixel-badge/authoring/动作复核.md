# 白龙娘互动逐帧复核

对照版本是提交 `d6ac563`。角色沿用同一份原画、同一 138 × 132 采样和审核过的待机图。对照时，在两版浏览器中用相同取景、同一触点执行同一个动作。

[右脸长按对照图](interaction-comparison.png)取自接触前、按住 1.60 秒、松手后 0.32 秒。[新版互动实录](../gesture-preview.webp)可看揉颊、顺毛回礼、星萤入掌，以及持书回应后翻页。

## 可复现的问题与处理

| 场景 | 上一版的表现 | 本次处理及实测 |
| --- | --- | --- |
| 点脸、长按、轻揉 | 直到松手才播放同一段反应。即使按住 1.6 秒，也仍显示待机脸 | 按下即进入被碰一侧的眯眼姿。保持接触停在第 3 帧，松手从当前帧回弹。两次足够长的换向才触发挠痒，手指抖动不会计数 |
| 沿刘海顺毛 | 手指来回几趟与单次划过的结果相同，松手后缺少她主动做的事 | 偏头跟随接触位置和方向。待机时完成两次有效换向再主动松开，她先回蹭，再用双爪捧心回赠。工作、失焦或滑出触区时各自回到原状态 |
| 读书时碰鼻尖 | 先收书 8 帧，再开始皱鼻。松手到第一张有鼻尖动作的帧，桌面 Chrome 三次为 428、430、431 ms | 直接从持书姿态回应，三次为 92、95、95 ms。两组均从全新页面进入同一阅读状态，以相同鼻尖触点计时。数字含本机图集解码与下一次绘制的等待 |
| 持物时摸头、碰翼或尾巴 | 短暂接触也可能让手上东西消失，返回时再次摆出 | 星图、月牙图、终端、镜片、手帐、纸签共六种持物场景，分别导出两侧摸头、鼻尖、喷嚏、两侧翅膀、尾尖共七种反应。写字和叠纸继续使用被打断的那一帧的双手与纸面 |
| 见星、追星、接星 | 按钮启动固定抛物线。使用者无法改变她追看的方向、落点或哪只手接 | 星萤由实际指针牵引，横向 9 档、纵向 3 档目光。慢慢放手或朝掌心轻抛可以接住，拖偏会绕回。她会看向接星的那只手、捧给你看，并记住这次用哪只手 |
| 星萤主动邀玩 | 待机只按固定时长入睡 | 接住一次后，再安静约 11.5 秒，她会从另一侧邀请一次。忽略邀请时保留已累计的安静时间，仍会入睡。减少动态效果模式保留按键和拖动，主动邀玩关闭 |
| 翻页与取消 | 在阅读起姿开始翻页，全身有 130 个像素变化、近景有 268 个变化。翻完接新页的两种取景分别跳 37、72 格。大幅竖划也可能提交翻页 | 校准书、眼神与手腕的边界姿态。星图和月牙图切换的标准起止帧逐像素一致。竖向滑离或向错误方向拖动将纸放回，横向短拖仍会触发偷瞄 |
| 入睡和醒来 | 点在哈欠中途可能直接跳到完全睡着的偷看姿态；很快再碰，眼睛也会直接跳到已经睁开的姿态。标准左侧偷看接醒来时近景另有 133 个像素跳变 | 哈欠中途从当前帧收势。睡稳后按触摸方向偷看，连续第二触会被记住，眼睛从当前开合程度补齐，再接伸展。桌面鼠标和手机模拟触屏实测，松手到首次可见姿态改变约 29–34 ms |
| 背景与反馈 | 墨绿色山脊把旧版紫色暮光、暖窗与湖面层次压平；短触在加载动作时缺少现场反馈 | 对照早期像素版恢复暮紫远山、金色月牙、天文台双窗和湖水反光。接触记号按真实触点绘制。圆屏顶部状态和底部数字使用单独区域，拖星到边缘也不会遮住读数 |

文中的“第 3 帧”以 0 为首帧。“零差异”指列出的两张衔接帧实际渲染后的 RGBA 像素完全相同。标准姿态的接缝检查与任意时刻中断动作的浏览器检查分别进行。

## 其余动作逐组检查

| 动作 | 检查重点 |
| --- | --- |
| 待机、左／右摸头、顺毛、献心 | 核对保留的待机原图、接触方向、松手回蹭。分辨静止长按、微小抖动与有方向的抚摸；顺毛的 45 格是 5 档压力和 9 个位置 |
| 左／右脸、鼻尖、喷嚏、翼、尾巴 | 按哪侧先动哪侧。鼻尖第二次快速接触才喷嚏，羽翼与尾尖在受碰后有延迟跟随 |
| 吃糖、吹泡泡、戳泡泡 | 保留入口、吹出、悬停、破裂与碎星落下。检查全身和带横移的近景都用当前帧的泡泡坐标命中 |
| 瞌睡、左右偷看、左右伸展 | 核对哈欠的 15 个入睡起点、20 个呼吸相位和偷看中第二次触碰。只有碰到角色才算叫醒 |
| 工作、完成、异常、待确认、取消、受限及结束 | 验证按作业前进、动作完毕后呼吸。亮键、镜片、击掌沿用逐帧目标；碰等待的小爪只触发本地表演 |
| 拖书角、回望、星萤左右落掌 | 检查手指松开、失焦、竖滑、拖偏和两种取景的实际输入。接星前最后的目光档位要与接星首帧一致 |

## 检查范围与复跑

- 左右送额邀请各有 89 个姿态。第 23 帧是等候，第 24–36 帧是贴近，第 37–54 帧是无人应答时理好刘海，第 55–64 帧是轻点收势，第 65–76 帧是反侧追视。第 77–82 和 83–88 帧分别从等候和靠稳接入原有顺毛图集。全身和近景分别导出。[近景触摸实录](../forehead-preview.webp)
- 57 个片段连同场景变体共 135 组，扫描全身与近景共 8,182 个取景帧、149,043,312 个索引像素，另有 336 个手纸前景帧对回原帧。
- 33 组动作接缝在两种取景下均为零差异。其中 24 组覆盖送额动作的分支、回正及切到顺毛的第一帧。91 个观星与接星姿态中的左右掌心均处于可触范围。
- 额外抽取 2,487 个骨架姿态检查可见三角形翻面和局部伸长。该批姿态没有检测到翻面，局部最大伸长均低于 1.5 倍。
- 在全身和近景实际调用六种持物场景的七种接触，共 84 次，均使用对应的持物图集，触碰时没有插入收放道具片段。桌面鼠标、手机浏览器模拟触屏、键盘及减少动态效果均走实际页面输入。桥接另验数值刷新、过期和断线。实物 AMOLED 亮度、设备端帧率和面板触摸延迟仍待上板测量。
