# 像素动作复核

本次复核以全像素网页的实际图集和圆屏输出为准。先扫描旧版 37 个片段及场景变体，共 4,104 个取景帧。新版有 51 个片段，加上按工作状态区分的反应后为 87 组。逐格扫描了 5,250 个角色取景帧、95,634,000 个索引像素，另将 336 个手与纸的前景帧逐像素对回原工作帧。

## 从帧里发现的问题

| 位置 | 旧版现象 | 处理与验收 |
| --- | --- | --- |
| 工作轮廓 | 思考、阅读、执行、写入、搜索、整理都被同一显示器和桌沿分割。阅读片段三分之一处全身仅有 5,554 个不透明格，而且包含桌子 | 去掉桌景，共用站姿。新阅读同一相对位置有 8,232 个不透明格。两爪从书的两端入画，翻页时右爪只抬起一小段，左爪继续支撑 |
| 循环方向 | 旧执行片段首尾相差 1,679 格，旧阅读相差 1,419 格。播放器用原路倒放来回避断点，也会倒放写字与庆祝 | 思考、阅读、执行、搜索与等待均从正向循环收回起姿。写入、整理及结束类状态完成后进入独立的三秒呼吸段。两种取景逐格比较，以上各段循环末帧与循环起点差异均为 0 |
| 手与物件接触 | 第一轮去桌后的口袋终端，右手落点与亮键还相差约 14 个全身像素。近景足以看出它在敲空气 | 以支撑终端的左手定位按键，将右爪横移和落指深度对准键面。在按下程度达到九成的 6 帧里，右掌锚点距键心为 0.02–0.38 个全身像素。点击区域与音符起点取同一个逐帧目标。镜片、举掌和书角各使用自己的锚点 |
| 摸脸和挠痒 | 旧戳脸在第 0 帧已经侧移。旧挠痒全身单次帧间最多改变 4,280 格，两只手同时抬高会带着书跳 | 从接触、退让、回望一路回到起姿，脸、发梢、翼尖错开。新版挠痒单次帧间峰值为 3,477 格。持物时只允许很小的抬手幅度。写入和整理额外锁定接触瞬间的双手与纸面 |
| 切换与取景 | 喂糖等动作会让工作道具突然消失。旧阅读近景相机也随桌景切换 | 收起或拿出道具各用 8 帧。中途再次切换，从当时的手位继续。普通工作共用近景相机，糖泡泡保留逐帧横移。顶部状态与底部读数占独立区域 |
| 睡醒和结束 | 通用按钮可直接让睡着的角色开始吃糖。完成状态会反复重演庆祝 | 熟睡时先偷看，再舒展。结束、取消、受限、异常和成功各自落在可呼吸的姿势上 |

## 动作逐组检查

| 片段 | 关键帧与验收点 |
| --- | --- |
| 待机、左／右摸头、顺毛 | 待机沿用审核过的形象。摸头先追视后偏头。顺毛图集的 45 格是 5 档接触深度 × 9 个方向，按手指取样，两行之间没有时间顺序 |
| 左／右脸颊、挠痒 | 碰哪侧先眯哪只眼，回弹时流苏继续摆。第三次有效点击才触发笑。两侧戳脸与挠痒的首末全身帧完全一致 |
| 鼻尖、喷嚏、左右翼、尾巴 | 鼻尖首次轻皱，快速再次触碰才喷嚏。被碰的一翼先收后展。尾根先收，尾尖和回望稍后跟上 |
| 接星、喂糖、戳破泡泡 | 保留原抛物线、嘴与掌的接触和泡泡横移。气泡稳定后才开放点击。两种取景均按实际气泡位置接触 |
| 打盹、左右偷看、左右醒来 | 前 15 帧进入睡姿。安静时进入 20 帧睡眠循环。偷看可自行闭回，第二次触摸才进入双翼依次舒展 |
| 读星图／月牙、双向翻页、回望 | 两张图的阅读循环各自闭合。25 个翻页姿态由横向拖动取样。松手可前进或弹回，完成后保留新图案 |
| 口袋终端、镜片、等待的小爪 | 执行的两次接触各有一个上扬音符。星屑从镜沿出现。掌边短线只出现在击掌瞬间。以实际鼠标分别点过全身和近景的三个道具 |
| 手帐、纸签及持物反应 | 戳脸、挠痒、顺毛期间使用中断帧的袖口、指尖和纸面。手部前景每个非透明像素均与原工作帧相同。返回时从原时间继续 |
| 思考、成功、结束、取消、受限、异常 | 思考是循环。成功有蓄力与落地。结束舒气、取消收手、受限垂翼、异常缩翼。后五种状态各保留自己的表情进入小幅呼吸 |

## 复查方法

从像素版目录运行。CSV 每行对应片段、场景、取景和帧号，记录轮廓范围、不透明格数、与上一格的差异、循环接缝及触点可见性。所有角色帧的额头、鼻尖及已导出的道具触点都在圆形可触区内。帧差用于定位异常动作，实际接触、读数和观感另在浏览器复看。

```sh
python authoring/audit.py --csv frames.csv --sheet poses.png
python authoring/preview_check.py --chrome "C:/Program Files/Google/Chrome/Application/chrome.exe"
node --test authoring/gestures.test.cjs
```

[工作互动实录](../work-preview.webp)和[陪玩实录](../gesture-preview.webp)来自网页播放器。此轮验证覆盖浏览器的全身、近景、触屏、键盘、减少动态效果和本地预览桥接。实物 AMOLED 的亮度、触摸手感及 ESP32 帧率仍待上板测量。
