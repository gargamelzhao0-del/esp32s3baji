# 白龙娘的道具与互动图标

此文记录月牙枕初版。随后针对支撑和收放重画了整段打盹，当前版本见[互动动作设计评审](互动动作设计评审.md)。

角色帧为 138 × 132。下表的屏幕坐标以 184 × 184 的圆屏为准，左上为原点，行号从 0 开始。可打开[网页模拟器](../index.html)，也可以打开[只看圆屏](../index.html?observe=1)，直接试画面里的触点。

## 先看打盹

旧 Z 只有 9 个淡紫色像素，靠近白发时很容易漏看。现在两枚大小不同的 Z 放在脸左侧的暗色天空，有深色轮廓，暖白与浅青字芯分别占 38 和 16 个像素。两只手依次松到裙边时，月牙枕从画面右侧滑到脸颊下面。枕头的内角藏到脸后，外沿露在肩前。可以按住枕面不同位置，看金色月牙和附近的布料一起下陷，下沿仍贴着肩。

睡稳后按枕头，她继续睡。点脸一次，她睁一只眼，Z 消失，脸仍靠着枕头。再叫一声，她伸展双手，枕头滑出。分别检查了提前叫醒、枕上松手、从枕面拖到脸上取消，以及圆屏获得焦点时用 P 按放枕头。[新旧实录](pillow-preview.webp)

## 陪玩动作

| 动作 | 此轮在圆屏上核对的细节 |
| --- | --- |
| 左右摸头、额头邀请、按住贴贴 | 普通轻点沿用左右偏头反应。她主动侧过额头等你时，受邀一侧的刘海多出两小笔高光，碰到便收起。两种取景下逐点检查，高光的每个像素都落在额头触区。 |
| 顺毛、蹭手、双爪送心 | 按住刘海到往返抚摸沿用同一根指针。松手能回蹭，满足往返条件才捧心。工作时抚摸也能回应，工作进度单独保留。 |
| 戳脸、揉脸、挠痒 | 复查按住、换向和松手。她会先保持一侧眯眼，松开才回弹；轻揉和连续轻点都能触发笑。手指滑出或取消时结束接触。 |
| 鼻尖、喷嚏、左右翼、尾尖 | 重画了鼻尖按钮。实际点击鼻尖并快速再点一次能触发喷嚏，左右翼分别命中。全身取景可点尾尖，近景裁切处看不到尾尖。 |
| 星糖与泡泡 | 原先糖已经吃掉，按钮仍画着糖。现在泡泡飘入可点阶段时，按钮切成泡泡，泡泡边缘出现高光。近景平移时提示跟着泡泡，点破即收起。 |
| 逗星萤、落空、左右手接星、收起 | 逗玩、送到手心和收起各用一个图标。把星萤送到一只手心、抛偏后再接、用键盘选择手心都有对应反馈。「收起星萤」使用回转箭头。 |
| 待机、自主理发、看左右、伸懒腰、哈欠、哼歌、抖翼和摆尾 | 复查了微动作调度、接触时手臂退回、额头邀请和自然入睡的先后。短反馈在互动结束时消退，待机时留出天空给下一次邀请。 |

## Agent 手中的五件道具

| 场景 | 原画面容易误读之处 | 现在可观察的动作 |
| --- | --- | --- |
| 阅读 | 图鉴下缘在近景被额度栏截住，翻页时右手抬得接近嘴 | 抬高支撑手，给书脊、封底和书签不同明度。星座图和月牙图随纸页翻转，右手从嘴下经过。拖一小段再松手可看纸页弹回。 |
| 执行 | 终端像一条进度条，按下哪个键很难判断 | 折角屏幕显示终端提示符，下方有独立键区。指尖接触右侧亮键时键帽才下沉，一次回应有两次按压。 |
| 写入 | 笔杆与本子不易分清，近景下猫脸的下半部分被裁 | 环装本加了侧环，羽笔有笔羽和深色笔尖。笔尖在页上落墨。中途戳脸再恢复时，笔迹和握笔的位置一起续上。 |
| 搜索 | 淡色镜片盖在脸前，难看出她在找什么 | 黄铜镜框配深色握柄，镜片采样并放大当帧画面 1.42 倍。点镜片后，她把镜心对到眼睛，再从镜沿闪出星屑。 |
| 整理上下文 | 错开的纸张像一块色板，收齐之后缺少区别 | 三张纸签露出不同色的索引边。她一张张收齐，保留边角层次。中途互动后，从原来的纸叠进度继续。 |

近景的底栏从第 149 行开始。原图鉴和绘本下方约 9–11 行被覆盖。调整后，图鉴、终端、绘本和纸签的下缘都在第 148 行以内。[六种工作互动同时播放](agent-props.webp)

## 其余 Agent 状态

思考用金色灯泡，等待确认用带回车箭头的青色对话框，完成用带勾的绿奖章，结束用淡紫色收工旗，取消用带停止键的八角牌，受限用斜纹路障，异常用三角叹号。图标保留到状态切换，即使只看单色轮廓也能分开。等待时与她击掌，顶栏仍显示 WAIT。真实会话切走时，旧标记随之清除。阅读等五种工具状态直接靠手中实物辨认，空闲时留出画面。[七种状态的实际圆屏](agent-state-marks.png)

## 复核方法

- [图集审计](audit.py)遍历了 64 个片段、142 个取景变体、8,474 张原生角色帧，逐像素核对 50 处动作接缝和另外 336 张手与纸张前景。所有帧做自动检查，关键接触与收放阶段另看实录。
- [工作道具检查](work_grip_check.py)检查了 21 段共 591 个骨架帧，包括握点、键帽下沉、镜心对眼、翻页时手与嘴的间距及底栏遮挡。[手指接触检查](face_contact_check.py)与[手掌轮廓检查](palm_contour_check.py)复查脸与手的局部动作。
- [枕头检查](nap_prop_check.py)在全身和近景、普通和减少动态四种组合下读取实际画布像素。普通模式两种取景的按压分别改变 58 和 80 个枕面像素。
- [互动提示检查](affordance_check.py)在全身鼠标与近景模拟触屏下，逐点核对刘海和泡泡高光的命中位置，并验证按钮随动作更换。[手势检查](contact_check.py)覆盖按住、松开、取消、错过玩具、主动邀请和键盘互动。
- [桥接与状态检查](preview_check.py)使用本地 Agent 桥接服务回放事件，验证互动中的顶栏、会话切换、指标过期与纸面进度恢复，并对两种取景下的静态图标做像素比较。以上复核运行于浏览器模拟器，真机亮度、实体尺寸和触摸手感仍需在圆屏上观察。
