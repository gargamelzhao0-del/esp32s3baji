## 摸摸她

想让第一次见她的人自己发现玩法，可以打开[只看圆屏](index.html?observe=1)。这个入口收起文字提示与动作按钮，直接触摸圆屏即可；页脚的「展开控制」可回到完整预览。

| 操作 | 圆屏里的反应 |
| --- | --- |
| 初次空闲约 7 秒，或在待机时点「伸手等她」 | 她拨开一侧刘海，侧过额头，放下爪子看着你。把指尖停在那一侧，她先眯起一只眼，再自己贴上来；摸另一侧，她会转眼去找手。快速松手，她从当时的姿势收回 |
| 她送出额头时，沿着刘海移动，再停下来 | 同一根手指就能从贴贴接到顺毛。你停下来，她自己补完半下，然后靠稳。一直没碰她，她会把刘海理平，同一段安静时间只邀请一次，约 28 秒照常打盹 |
| 轻点额头左侧或右侧 | 她先看向那只手，再闭眼歪头蹭过来 |
| 按住刘海，沿发梢往返抚摸 | 她随手指偏头，松手时主动回蹭。待机时完成两次明显换向再松手，她会双爪捧起一颗心送给你 |
| 按住一侧脸颊，轻揉或松开 | 按住时保持单侧眯眼，松手才回弹。来回轻揉两次换向会挠痒笑，轻点三下也能触发 |
| 轻点鼻尖，再快速点一次 | 先皱鼻子，再蓄一下气打喷嚏 |
| 点翅膀或尾尖 | 被碰的一侧先躲，另一侧的翼或视线随后追过来 |
| 喂星糖，等泡泡飘到旁边再点 | 吃糖、吹泡泡、戳出碎星。近景镜头跟随泡泡 |
| 点「逗星萤」，拖住发亮的小星 | 把星萤举高、移低或绕到另一侧，她的眼睛和头会跟过去。把它放在任一只手心，或朝手心轻抛，她会接住、捧起、眨眼。错过时星萤会绕回来，也可以直接点手心 |
| 接过星萤后让她歇一会儿 | 安静约 11.5 秒后，她会从上次接星的另一侧再邀请一次。继续让她休息，星萤会自行离开，她按原来的安静时间入睡。减少动态效果模式由你主动邀玩 |
| 待机约 28 秒，或点「打个盹」 | 哈欠、收翅、入睡。在哈欠中碰她，她会沿当前姿势回应。熟睡后轻碰会睁一只眼，趁她偷看再碰一次才会伸懒腰 |

## 动作导演 v2

待机不再只是一条循环：她会看左/看右、理刘海、伸懒腰、哼歌、打哈欠、抖翅膀、摇尾巴、皱鼻子。微动作每 3.8–7.2 秒挑一次，被打断、被按住、需要你确认或打盹时会停下；每次互动后也会先安静一会儿，再把注意力放回你身上。状态切换会冒出问号、感叹号或省略号气泡；摸头、顺毛、戳脸、击掌、接星会飘心、星屑、汗滴或音符。设置里的「她记得你」记录本机亲密度：初见、好奇、亲近、黏人、默契。

- `index.html?motion=legacy`：一键回到旧行为，用于回滚或对比。
- 减少动效：关闭微动作和漂浮表情，保留状态文案与静态反馈。
- 导演逻辑在 [`motion.js`](motion.js)，完整设计见 [`MOTION-V2.md`](MOTION-V2.md)。

## 陪她工作

用「Agent 状态」切换工作。在圆屏上直接点道具，也可以使用「陪她玩」下方随状态变化的按钮。

| 状态 | 可观察或触发的动作 |
| --- | --- |
| 思考 | 托爪、斜上方看、呆毛迟半拍弹起 |
| 阅读 | 捏住书的右角向左拖。短拖松开，她把纸页弹回，偷瞄你一下。拖过约六成或点书角，可以在星图与月牙图之间翻页 |
| 执行 | 左手托口袋终端。碰右侧亮键，她用两次落指、两个跳音符和一次眨眼回应 |
| 写入 | 左手托本，右手的笔尖沿纸面落墨。戳脸或顺毛时，手和纸停在当前帧，回应后接着写 |
| 搜索 | 碰镜片，她眯眼凑近，找到的星屑从镜沿闪出 |
| 等待确认 | 碰举起的手就能击掌。这个回应只发生在吧唧上，Agent 审批继续在电脑端处理 |
| 整理上下文 | 把松散纸签收齐。戳脸时保留纸叠进度 |
| 完成、异常、受限、结束、取消 | 各有庆祝、缩翼、休息、舒气、收手的节奏。完成动作后仍有呼吸、眨眼和尾尖小动作 |

圆屏获得焦点后，空格或回车触发当前场景互动，按住左右方向键可以顺毛。她送额头时，空格或回车可按住再松开，Esc 可以结束邀请。「把手给她」按钮也可以代为停留片刻。减少动态效果模式下，可以主动轻触额头，用静止姿态完成贴贴。逗星萤时，左右键选手，回车送出，Esc 收起。全身和近景都使用 **138 × 132** 的原生角色帧，独立圆屏画布为 184 × 184 格，包含外壳。暮紫色山湖、金月和亮窗天文台依据早期像素版的画面重新绘制。网格默认开启。取景与网格偏好保存在本机。

## 圆屏读数

左侧是当前桥接提供的第一个额度窗口的**剩余百分比**，右侧是**上下文已用百分比**。薄荷色和浅紫色横线分别跟随两个读数。估算值带 `~`，未提供或已过期显示 `--`，有效零值显示 `0%`。

直接打开首页时圆屏标记 `SIM`，显示演示值。运行工程的 Agent 预览服务后，打开[桥接模式](http://127.0.0.1:8765/badge/design/pixel-badge/index.html?agent=1)。`LIVE` 表示在线，`PLAY` 表示回放，`END` 表示已结束，`SYNC` 表示等待连接，`OFF` 表示离线或当前无适用会话。仅含输入、输出 token 数的 Codex 事件无法提供这两个百分比。

可在工程根目录运行以下命令，通过随包样例验证整个链路。

```sh
python tools/agent_preview.py --replay protocol/fixtures/codex-flow.jsonl --step 2
```

## 素材与制作

角色和字体署名见[素材与许可](credits.html)。[姿态脚本](authoring/poses.js)使用原版白龙娘的骨架、手臂和绘制层。[导出器](authoring/bake.py)把两种取景分别光栅化为索引色帧。现场播放按需读取图集，笔迹与纸签有单独的双手前景层。制作工具依赖 Python、NumPy、Numba、Pillow、Playwright 和 Chromium，浏览器预览直接读取导出成品。

新增或修改待机微动作后，只烘焙指定片段并合并元数据，不重写旧素材：

```sh
python authoring/bake.py --chrome "C:/Program Files/Google/Chrome/Application/chrome.exe" \
  --only idleLookLeft idleLookRight idleGroomLeft idleGroomRight idleStretch idleHum idleYawn
```
