# GPT 白龙娘

在角色页选“工作中”，看她把滚轮电脑桌从右边拖过来，坐定后按亮折叠屏，伸爪敲键。轻碰桌上的屏幕，她会转给你看。想单独玩，打开“口袋 → 小剧场”。三次轻点尾巴会惹她鼓起脸，喂星糖可以和好。短时间内左右手各成功击掌一次也能让她跳起来庆祝。[玩圆屏原型](../badge-prototype.html) · [观看 20 秒动作实录](desk-story-preview.webp) · [动作分镜、调研与设备端方案](../../docs/10-character-acting.md)

双击圆屏原型，选“阅读”，捏住书的右角往左翻。点圆屏右侧的“口袋”可以给她扎上樱花结，再回来看她读书。圆屏左侧的小物件随 Agent 状态变化。[打开圆屏](../badge-prototype.html) · [观看工作互动和口袋](agent-pocket-preview.webp) · [观看击掌和引萤](gpt-pet-preview.webp)

## 白龙的口袋

“陪她工作”显示本阶段能做的事。“一起玩”收着星糖、抛星、击掌和引萤等五种互动。“小衣橱”可以选择原装、樱花结、月牙夹或嫩叶夹。发饰跟随头部转动，浏览器记住上次的选择。按 Esc 可以合上口袋或收起当前工作互动。

| Agent 的状态 | 在圆屏上怎么玩 |
| --- | --- |
| 待命、思考 | 待命时摇铃，她会侧耳听。思考时点亮小灯，她会抬眼看亮光。 |
| 阅读 | 从书的右角向左划，纸页跟着手指绕过书脊。只翻一点便松手，纸会弹回。轻点书角也能翻页。 |
| 写入 | 点印章，她在本子上按出梅花爪印。 |
| 执行工具 | 跟着亮键依次敲左、右、左三拍。错拍可以接着来，最后一拍落下，她会用尾巴跟一下拍子。打开口袋右上角的“音效”后，三次敲击会奏出三个逐渐升高的音。 |
| 搜索、整理上下文 | 搜索时点星屑，看她用放大镜对准它。整理时碰纸角，她会折出一架小飞机。 |
| 等待确认 | 碰她举起的手，她点头抱住信封。电脑端的确认仍由用户完成。 |
| 异常、受限 | 异常时可以贴一张星星贴，受限时可以递一杯冒热气的茶。 |
| 普通结束、明确成功、取消 | 普通结束时合上手帐，明确成功时拉响礼花，取消时把笔收回袋里。 |
| 断开连接 | 拨动纸风车。工作状态与额度随连接情况单独显示。 |

活跃工作期间，来源每报告一位助手，画面多出一只纸鹤，最多同时画两只。口袋里显示来源提供的实际数量。轻碰纸鹤，它会扑翅，她的视线也跟过去。手动演示可勾选“两位助手协作”。工作玩法支持空格或回车，合奏还可以用左右方向键。

## Agent 联动

直接打开 HTML 可手动切换所有场景。要试完整的数据路径，在开发目录运行下列命令。它使用项目自带的八条 Codex 快照，每四秒推进一次。浏览器进入桥接器打印的本地地址后，页面会标为“事件回放”。[打开默认本地地址](http://127.0.0.1:8765/)

```powershell
python tools/agent_preview.py --replay protocol/fixtures/codex-flow.jsonl
```

要跟随一次实际的 Codex CLI 任务，在平时运行 Codex 的项目目录中执行下面的 PowerShell 命令。在浏览器打开终端打印的地址。本次任务所选的模型 ID 同时传给 Codex 和桥接器，缺少型号时圆屏显示未知。任务结束后可以继续查看结果，Ctrl+C 关闭预览桥。[Codex 官方 JSONL 事件说明](https://developers.openai.com/codex/noninteractive#make-output-machine-readable)

```powershell
$badgeModel = Read-Host '本次使用的模型 ID'
$badgeTask = Read-Host '这次交给 Codex 的任务'
codex exec --json --model $badgeModel $badgeTask | python 'D:\esp32电子吧唧\esp32s3baji\tools\agent_preview.py' --model $badgeModel
```

桥接器只监听本机回环地址。它接受标准输入中的 Codex JSONL、BAJI v1 快照 JSONL 和项目的 CRC 分帧格式。本地网页只接收投影后的状态、型号和指标。Codex 的命令、搜索、文件更改等已知事件按类型映射。BAJI 快照还能明确提供阅读、等待确认、受限、助手数量和完成结果。普通的 `turn.completed` 对应“本轮已结束”。若来源只给出 Token，用量页显示该轮输入和输出，额度与上下文占用显示“—”。[桥接器](../../tools/agent_preview.py) · [状态投影](../../host/baji_bridge/preview.py)

联动页面跟随最新状态，右侧保留最近四次可见变化。BAJI 实时快照八秒未更新会显示离线，额度与上下文分别按各自的有效期失效。当前接入针对提供事件流的程序。自动订阅已打开的 Codex 桌面会话，以及通过 USB 在 ESP32 上显示，仍待实现。

## 平时和她玩

| 在圆屏上怎么玩 | 她会怎么回应 |
| --- | --- |
| 点左手或右手，再点举起的手心 | 击中时有短促的击掌光纹。碰到另一只手，她继续等。等约 7 秒，她自己收手。 |
| 长按手心约 0.7 秒，接着拖动手指 | 萤火虫会跟过来。把它引到任意一只手旁，慢下来停约半秒，她会托起它，看着它再飞走。鼠标可直接移动指针。 |
| 碰一侧翅膀或蜷起的尾巴 | 那一侧翅膀先抖，她随后转头。碰尾巴时，她会先把尾巴收走，再摆回来。 |
| 点鼻尖，然后在约 0.8 秒内再点一次 | 第一下她会盯住鼻尖，第二下她吸气、打喷嚏，头发随后回落。 |
| 揉额头、喂一颗星糖，或从袖口向上抛星 | 她随抚摸方向蹭手，伸手吃糖，或沿抛物线追星。松手位置和方向决定她在哪里接。 |

圆屏下方有“和她击掌”和“引萤火虫”按钮。选定玩法后，空格或回车可以击掌、引虫到手心，方向键可以移动萤火虫，Esc 结束。开启“减少动效”后，点手心或按键会给出静止的反馈，邀请会等到你操作。

**她如何行动**

- 待命时，眼睛先转，头和发饰随后跟上。独处几秒她会扭头看尾巴或听一听侧翼的动静。约 17 秒时会打一个哈欠，约 22 秒开始打盹，到约 27 秒合眼。此时把指针移回来，她会先睁一只眼，再依次伸展两侧翅膀。
- 成功击掌或接住萤火虫后，让她安静约 5 秒。她会用刚才的手再挥一下，或低头查看萤火虫停过的位置。这段回忆在当前页面短暂保留，每次成功互动最多重现一次。
- 持续抚摸时，她会保持蹭手的姿势，随抚摸方向歪头。喂糖有伸手、送到嘴边、咀嚼三个阶段。接星有预蹲、起跳、伸手和落地回弹。
- 阅读时视线逐行移动，书页绕着书脊翻过。写入时羽毛笔跟随右手。执行工具时两手交替敲键，搜索时举起放大镜。工作动作之间共享同一个身体姿势，肩膀、眼睛和手中的道具逐渐过渡。
- 抚摸、吃糖、接星、击中手心或成功接住萤火虫，各记一次亲密互动。浏览器保存本机关系进度，关系越熟悉，抚摸时的倾头和摆尾稍大。停用本地存储时进度持续到本次页面关闭。
- 断开电脑后，白龙娘收起工作道具，仍可以陪玩。状态胶囊继续显示连接情况，主屏用量显示“—”。在系统或页面开启“减少动效”时，以静止表情和文字回应。离开角色页或把标签切到后台时，动画时钟暂停。

**如何修改动画**

| 文件 | 用途 |
| --- | --- |
| [face.js](face.js) | 单独控制两侧眼睑，绘制虹膜、光点、渐变腮红和嘴形。萤火靠近时会在眼中映出暖光。 |
| [rig.js](rig.js) | 在 569 × 640 原画上划分头、手、双翼、尾巴与发梢。把手心、鼻尖、侧翼及手指轮廓绑定到实际显示的三角面。 |
| [companion.js](companion.js) | 协调 Agent 活动、注意力、触碰、短期回忆、打盹与苏醒。弹簧控制各部位的跟随速度。 |
| [stage.js](stage.js) | 搬桌、开机、指屏、双跳、闹别扭和和好的动作时序、脚步及接触目标。 |
| [stage-art.js](stage-art.js) | 绘制有前后遮挡的桌椅、折叠显示器、各工作状态的屏幕内容和情绪特效。 |
| [play.js](play.js) | 处理击掌的命中、等待和收手，以及引萤时的引导方向、接近速度、停留、落手和飞离。 |
| [work.js](work.js) | 工作状态与本地玩法的对应关系，处理翻页拖动、三拍命中、中断和静止反馈。 |
| [desk-art.js](desk-art.js) | 圆屏和菜单共用的道具与发饰画法，以及协作纸鹤的飞行位置。 |
| [chimes.js](chimes.js) | 点击后本地合成铃声、盖章声及三拍短音。音效默认关闭，开关保存在本机浏览器。 |
| [pocket.js](pocket.js) | 口袋分栏、选物、键盘与焦点、穿戴记忆。 |
| [props.js](props.js) | 绘制工作道具、落脚阴影、萤火与击掌光纹。道具经过手心时按照手指轮廓处理遮挡。 |
| portrait.js | 原始立绘的 WebP 字节，内嵌在本地脚本中，让双击 HTML 时也能离线读取画面像素。 |

浏览器以每秒 30 帧为调度目标。搬桌与心情短片录自 466 × 466 的完整圆屏，每秒采样 20 次。早期击掌与引萤短片为 420 × 420，每秒 18 帧。ESP32 的资源大小、触摸手感与刷新速度仍待上板验证。
